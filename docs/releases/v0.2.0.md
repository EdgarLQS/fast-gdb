# fast-gdb v0.2.0

> 当前为本地开发候选说明，不代表 v0.2.0 发布门禁已经全部通过。

v0.2.0 在 Reader-only 边界内新增统一 C++ 访问入口和只读 GDAL 插件。本地 `.gdb`
默认走 fast-gdb；S3 和白名单内的能力缺口通过官方 GDAL/OpenFileGDB 处理。

## 新增能力

- `fast_gdb::unified`：
  - `Dataset / Group / Layer / Feature / FeatureCursor`；
  - `Auto / FastOnly / GdalOnly`；
  - 拥有型字段和几何；
  - `Unset / Null / Value` 字段状态；
  - 正数 signed 64-bit FID；
  - Root Group 和 Feature Dataset 层级；
  - Schema freeze 和 fallback parity；
  - `Native / FidAscending`；
  - 有界且原子发布的 `read_all()`；
  - `CapabilityReport / BackendReport / QueryPlan / QueryReport`。
- `FastLayerExtensions`：
  - 仅 fast 后端可用；
  - FileGDB 物理字段描述符；
  - 零基 row slot；
  - 有上限的原始记录字节。
- 共享 `fast_gdb_runtime`：
  - facade 和插件共用进程级 coordinator；
  - 每个 Cursor 独占 Reader 或 GDALDataset；
  - runtime/plugin build ID 握手。
- `FastFileGDB`：
  - 独立只读 GDAL vector driver；
  - 显式 `-if FastFileGDB` 或 allowed-driver 打开；
  - 不替换官方 `OpenFileGDB`；
  - update/create/delete/transaction 明确不支持。

## 构建与使用

```bash
cmake -S . -B build \
  -DFAST_GDB_WITH_GDAL=ON \
  -DFAST_GDB_BUILD_UNIFIED=ON \
  -DFAST_GDB_BUILD_GDAL_DRIVER=ON
cmake --build build --parallel
cmake --install build --prefix /path/to/prefix
```

CMake consumer：

```cmake
find_package(fast_gdb 0.2 CONFIG REQUIRED)
target_link_libraries(my_reader PRIVATE fast_gdb::unified)
```

GDAL 插件安装到：

```text
<prefix>/lib/gdalplugins/<gdal-major.minor>/gdal_FastFileGDB
```

调用方自行设置 `GDAL_DRIVER_PATH`，项目不会修改宿主进程的全局配置。

## S3 状态

`s3://bucket/prefix/data.gdb` 会规范化为 `/vsis3/bucket/prefix/data.gdb`，并且只允许
官方 `OpenFileGDB`。当前没有真实 AWS 凭据、目录枚举、Range Read、403/404、超时、
断网和性能证据，因此 S3 状态是 **Experimental / Unverified**。

MinIO、OSS、COS 和其它 S3-compatible 服务不继承 AWS 的未来验收结论。

## 不变边界

- Reader only；
- 不提供 FileGDB Writer；
- 不提供远程事务、对象锁或原子多对象发布；
- 本地编辑仍要求关闭 Reader、使用 GDAL 编辑、`GDALClose()`、完整重开；
- 已返回 Cursor 不在读取中途切换后端。
