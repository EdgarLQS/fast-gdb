# fast-gdb v0.1.0

This is the first scoped production release of the fast-gdb FileGDB Reader and geometry engine.

## Highlights

- Dependency-free C++17 Reader (`fast_gdb_linear`).
- Optional GDAL Hybrid Reader (`fast_gdb_hybrid`).
- ISO WKB-first output for Point, MultiPoint, Polyline and Polygon, including multipart, holes, islands and Z/M/ZM.
- Built-in CircularArc, CubicBezier and EllipticArc linearization.
- Correct ArcGIS `0x42` omitted-M-array handling for M-enabled 2D curves.
- Exact bbox/spatial filtering, explicit FID mapping and fail-closed corrupt geometry handling.

## Verification

The real `Curve_Polyline_M_FC` layer in `testcurve.gdb` passed 2/2 features with the pure C++ `BuiltinCurve` backend and zero GDAL fallback. FID mapping, WKB type, bbox, length and whole-layer spatial query passed. Release and ASan/UBSan/LSan executions reported zero failures.

Cross-platform release gates cover Windows, Linux and macOS pure C++, Linux Hybrid, GDAL product build and sanitizer checks.

## Packages

- Windows pure C++ linear package.
- Linux pure C++ linear package.
- macOS pure C++ linear package.
- Linux GDAL Hybrid package.

Packages contain libraries, public headers, CLI tools where enabled, CMake package metadata, project documentation and the changelog.

## Boundaries

- Curves are emitted as linearized standard WKB, not native curve WKB.
- MultiPatch is Hybrid degraded support only.
- Unknown or future ArcGIS/FileGDB encodings are outside the declared support matrix.
- Writer functionality remains experimental.
