# fast-gdb v0.1.0

fast-gdb 的首个能力范围正式版本，提供 C++17 FileGDB Reader、统一几何模型、标准 WKB 输出以及可选 GDAL Hybrid 回退。

## 主要能力

- 无 GDAL 依赖的 `fast_gdb::linear` 产品；
- 可选 GDAL 回退的 `fast_gdb::hybrid` 产品；
- Point、MultiPoint、Polyline、Polygon；
- multipart、洞、岛中岛、Z、M、ZM；
- CircularArc、CubicBezier、EllipticArc 内置线性化；
- ArcGIS/FileGDB `0x42` 缺失-M 数组编码兼容；
- ISO WKB-first 输出；
- 显式 FID 映射和 `.spx` 辅助空间过滤；
- 可重定位 CMake package 和 CPack 归档。

## 真实数据门禁

上传的 `testcurve.gdb.zip` 已与 GDAL/OpenFileGDB 对照：

- `Curve_Polyline_M_FC` 2/2 要素全部由 `BuiltinCurve` 解析；
- 0 次 Hybrid/GDAL fallback；
- FID 映射、WKB 类型、bbox、长度和整层空间查询全部通过；
- Release 与 ASan/UBSan/LSan 真实数据复验均为 0 失败。

## 发布资产

- Windows x64 纯 C++ ZIP；
- Linux x64 纯 C++ TGZ；
- macOS 纯 C++ TGZ；
- Linux x64 Hybrid TGZ，链接/运行时需要 GDAL；
- 所有归档的 `SHA256SUMS.txt`。

## 能力边界

- 曲线以线性化标准 WKB 输出，不保留 ArcGIS 原生 curve object；
- MultiPatch 仅提供 Hybrid degraded support；
- Writer 仍为实验性组件，不在 v0.1.0 生产支持声明内；
- 未知或未来 FileGDB 几何编码不在本版本承诺范围。
