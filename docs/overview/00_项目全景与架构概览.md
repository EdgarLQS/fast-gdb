# fast-gdb 项目全景与架构概览

## 1. 项目定位

fast-gdb 是 C++17 FileGDB Reader。核心目标是：

- 低依赖读取；
- mmap 和顺序扫描性能；
- FID、属性和空间查询；
- ISO WKB-first 几何输出；
- 与 GDAL 的正确性对照；
- 可选 GDAL Hybrid 复杂几何回退。

项目不实现 FileGDB Writer，也不维护 GDAL 写入包装层。所有编辑由调用方直接使用 GDAL/OpenFileGDB 或 ArcGIS 完成。

## 2. 产品

```text
fast_gdb::linear
    pure C++ Reader

fast_gdb::hybrid
    fast-gdb Reader + GDAL fallback
```

不存在 Writer target、Writer 公共头或 Writer ABI。

## 3. 代码架构

```text
src/edgar/explorgdb/common
    binary helpers / shared infrastructure

src/edgar/explorgdb/reader
    catalog / table / tablx / spx / atx
    query / cursor / geometry / WKB

src/edgar/explorgdb/curve_gdal
    optional GDAL geometry fallback

tests/usegdal/test_*.cpp
    direct GDAL fixture / parity / boundary tests
```

## 4. Reader 链路

```text
FileGDB directory
    → GdbCatalog
    → CatalogResolver
    → GdbTableParser
    → QueryEngine
    → FeatureCursor
    → FeatureRecord + GeometryValue
    → ISO WKB
```

## 5. 外部编辑边界

```text
Reader phase
    fast-gdb owns read state

Edit phase
    all fast-gdb objects closed
    GDAL owns update state
```

同一目录边写边读不支持。写后必须完整重开 Reader。

## 6. 在线更新

不停读更新需要业务层维护两个 GDB 副本并切换逻辑路径。该发布层不属于 fast-gdb。

## 7. 质量门禁

- pure Reader build and install；
- linear/hybrid package consumer；
- geometry and query regression；
- direct GDAL parity；
- GDAL 写后完整重开；
- 同目录重叠访问观测性测试；
- Windows/Linux/macOS Reader 矩阵。

## 8. 非目标

- FileGDB 创建和编辑；
- GDAL Writer wrapper；
- 事务、回滚和恢复；
- Reader/Writer 锁；
- generation 发布；
- Schema migration；
- 在线副本管理；
- 外部写入自动检测；
- 写后局部 refresh。
