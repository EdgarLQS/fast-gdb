# GDB 组件库使用教程

## 概述

本组件库基于 SuperMap iObjects 的 `Datasource→Dataset→Recordset` 三层模式，用 C++17 封装 GDAL OpenFileGDB 驱动的操作。设计目标是：

- **API 友好**：链式调用、类型安全、RAII 资源管理
- **忠实映射**：不承诺 GDAL 不支持的能力（如 OpenFileGDB 的事务）
- **线程安全**：通过连接池实现进程内多线程隔离

## 架构

```
GdbConnectionInfo → 连接配置（路径、别名、只读标志、Open 选项）
GdbDatasource      → 数据源（拥有 GDALDataset*，唯一所有者）
    └── GdbDatasets → 图层集合视图
        └── GdbDataset → 单个图层视图
            └── GdbRecordset → 记录集视图（顺序游标）

GdbField       → 值类型（Null/Integer/Integer64/Real/String）
GdbFeature     → 要素（FID + 几何 + 命名字段）
GdbQueryBuilder → 链式查询构建器

GdbConnectionPool → 线程安全连接池（唯一线程安全对象）
GdbBatchWriter    → 批量写入器（每线程独立连接）
```

## 1. 只读遍历（Phase 1A）

### 1.1 打开数据源

```cpp
#include "datasource.h"
#include "datasets.h"
#include "dataset.h"
#include "recordset.h"

// 方式一：快捷打开
GdbDatasource ds;
if (!ds.openExisting("/path/to/data.gdb")) {
    std::cerr << "打开失败: " << ds.getLastError() << std::endl;
    return;
}

// 方式二：通过 GdbConnectionInfo（支持更多配置）
GdbConnectionInfo info;
info.setServer("/path/to/data.gdb");
info.setReadOnly(true);
info.setOpenOption("MAX_OPEN_FILES", "500");

GdbDatasource ds2;
if (!ds2.open(info)) {
    std::cerr << "打开失败: " << ds2.getLastError() << std::endl;
    return;
}
```

### 1.2 枚举图层

```cpp
GdbDatasets datasets = ds.getDatasets();
std::cout << "图层数: " << datasets.getCount() << std::endl;

for (int i = 0; i < datasets.getCount(); i++) {
    GdbDataset layer = datasets.get(i);
    std::cout << "  [" << i << "] " << layer.getName()
              << " type=" << layer.getGeometryType() << std::endl;
}

// 按名称获取
GdbDataset cities = datasets.get("cities");
if (!cities.isValid()) {
    std::cerr << "图层不存在: " << datasets.getLastError() << std::endl;
}
```

### 1.3 遍历要素

```cpp
GdbDataset cities = ds.getDatasets().get("cities");

std::cout << "要素数: " << cities.getFeatureCount() << std::endl;
std::cout << "字段数: " << cities.getFieldCount() << std::endl;

// 输出字段信息
for (int i = 0; i < cities.getFieldCount(); i++) {
    std::cout << "  " << cities.getFieldName(i)
              << " (" << cities.getFieldTypeName(cities.getFieldType(i)) << ")"
              << std::endl;
}

// 遍历记录
GdbRecordset rs = cities.getRecordset();
while (rs.moveNext()) {
    std::cout << "FID=" << rs.getFid()
              << " name=" << rs.getFieldAsString("name")
              << " pop=" << rs.getFieldAsInteger("population")
              << " geo=" << rs.getGeometry()->getGeometryName()
              << std::endl;
}
```

### 1.4 读取几何

```cpp
GdbRecordset rs = cities.getRecordset();
while (rs.moveNext()) {
    const OGRGeometry* geom = rs.getGeometry();
    if (!geom) continue;

    switch (geom->getGeometryType()) {
    case wkbPoint: {
        const OGRPoint* pt = (const OGRPoint*)geom;
        std::cout << "Point(" << pt->getX() << ", " << pt->getY() << ")" << std::endl;
        break;
    }
    case wkbPolygon: {
        char* wkt = nullptr;
        geom->exportToWkt(&wkt);
        std::cout << "WKT: " << wkt << std::endl;
        CPLFree(wkt);
        break;
    }
    }
}
```

> **注意**：`getGeometry()` 返回的指针由 OGRLayer 管理，生命周期与当前 Recordset 绑定。如需长期持有，使用 `rs.cloneGeometry()`。

## 2. 事务（Phase 1B）

### 2.1 事务能力检测

```cpp
GdbDatasource ds;
ds.openExisting("/path/to/data.gdb");

std::cout << "支持原生事务: " << ds.supportsTransactions() << std::endl;
std::cout << "支持模拟事务: " << ds.supportsEmulatedTransactions() << std::endl;
```

> **OpenFileGDB 注意**：OpenFileGDB 驱动不原生支持事务。`supportsTransactions()` 返回 false。

### 2.2 手动事务

```cpp
if (!ds.beginTransaction()) {
    std::cerr << "开启事务失败: " << ds.getLastError() << std::endl;
    return;
}

// ... 执行写入操作 ...

if (!ds.commitTransaction()) {
    ds.rollbackTransaction();  // 失败时回滚
    std::cerr << "提交事务失败: " << ds.getLastError() << std::endl;
}
```

### 2.3 RAII 事务

```cpp
{
    GdbTransaction txn(ds);  // 自动 begin
    // ... 执行写入操作 ...
    if (!txn.commit()) {
        std::cerr << "提交失败: " << ds.getLastError() << std::endl;
    }
    // 析构时：若未 commit 则自动 rollback
}
```

## 3. 写入操作（Phase 1C）

### 3.1 创建图层

```cpp
GdbDatasets datasets = ds.getDatasets();

GdbDataset newLayer = datasets.create("points", wkbPoint);
std::cout << "创建图层: " << newLayer.getName() << std::endl;

// 删除图层
bool removed = datasets.remove("points");
std::cout << "删除结果: " << (removed ? "成功" : "失败") << std::endl;
```

### 3.2 添加要素

```cpp
GdbDataset cities = ds.getDatasets().get("cities");
GdbRecordset rs = cities.getRecordset();

// 添加新要素
OGRPoint pt(116.4, 39.9);
if (rs.addNew(&pt)) {
    rs.setField("name", "北京");
    rs.setField("population", 2154);
    rs.update();
}
```

### 3.3 编辑要素

```cpp
GdbRecordset rs = cities.getRecordset();

// 找到目标要素
while (rs.moveNext()) {
    if (rs.getFieldAsString("name") == "北京") {
        rs.edit();
        rs.setField("population", 2200);
        rs.update();
        break;
    }
}
```

### 3.4 删除要素

```cpp
// 删除当前要素
GdbRecordset rs = cities.getRecordset();
while (rs.moveNext()) {
    if (rs.getFieldAsString("name") == "北京") {
        rs.deleteCurrent();
        break;
    }
}

// 删除全部要素
cities.getRecordset().deleteAll();
```

## 4. 值类型与查询（Phase 2）

### 4.1 GdbField 值类型

```cpp
#include "field.h"

// 创建各种类型的值
GdbField nullField;           // Null
GdbField intField(42);        // Integer
GdbField int64Field(1LL<<40); // Integer64
GdbField doubleField(3.14);   // Real
GdbField strField(std::string("hello"));  // String

// 类型转换
std::cout << intField.asInteger() << std::endl;      // 42
std::cout << doubleField.asDouble() << std::endl;    // 3.14
std::cout << strField.asString() << std::endl;       // "hello"
std::cout << nullField.isNull() << std::endl;        // true

// 从 OGRFeature 自动推断类型
GdbField f = GdbField::fromOgrField(ogrFeature, fieldIndex);
```

### 4.2 GdbFeature 要素

```cpp
#include "feature.h"

// 创建要素
GdbFeature feat;
feat.setField("name", GdbField(std::string("北京")));
feat.setField("population", GdbField(2154));
feat.setField("area", GdbField(16410.54));

OGRPoint pt(116.4, 39.9);
feat.setGeometry(std::unique_ptr<OGRGeometry>(pt.clone()));

// 读取字段
auto nameVal = feat.getField("name");
std::cout << nameVal.asString() << std::endl;

// JSON 输出
std::cout << feat.toJson() << std::endl;
// 输出: { "fid": -1, "geometry": "POINT (116.4 39.9)",
//         "fields": { "name": "北京", "population": 2154, "area": 16410.54 } }

// 从/到 OGR 互转
OGRFeature* native = feat.toNative(layerDefn);
GdbFeature restored = GdbFeature::fromNative(native);
OGRFeature::DestroyFeature(native);
```

### 4.3 GdbQueryBuilder 链式查询

```cpp
#include "query_builder.h"

// 构建查询
GdbQuery q;
q.where("population > 1000")
 .limit(5);

// 执行查询
GdbRecordset rs = cities.query(q);
while (rs.moveNext()) {
    std::cout << rs.getFieldAsString("name") << " : "
              << rs.getFieldAsInteger("population") << std::endl;
}

// 计数（不解包要素）
int64_t total = cities.count(q);
```

> **注意**：OpenFileGDB 驱动对 `SetAttributeFilter()` 的支持程度有限，部分 WHERE 条件可能需要在内存中过滤。

### 4.4 空间关系查询

`GdbQuery::spatial()` 支持 4 种空间关系：`Intersects`（默认）、`Contains`、`Within`、`Disjoint`。

GDAL 的 `SetSpatialFilter()` 仅做 bbox 相交预过滤，其他关系需在 `Recordset::moveNext()` 中后过滤。详见 `docs/013_GDB_空间关系查询说明.md`。

```cpp
#include "query_builder.h"
#include "spatial_relation.h"

// 构建查询几何
OGRPolygon bbox;
OGRLinearRing ring;
ring.addPoint(112.0, 21.0);
ring.addPoint(115.0, 21.0);
ring.addPoint(115.0, 24.0);
ring.addPoint(112.0, 24.0);
ring.closeRings();
bbox.addRing(&ring);

// 默认 Intersects（bbox 相交）
GdbQuery q;
q.spatial(&bbox);
GdbRecordset rs = cities.query(q);

// 指定空间关系
GdbQuery q2;
q2.spatial(&bbox, GdbSpatialRelation::Within)
   .where("population > 10000000");

// Disjoint：不在 bbox 内的要素（无预过滤优化，需全表扫描）
GdbQuery q3;
q3.spatial(&bbox, GdbSpatialRelation::Disjoint);
```

| 关系 | 预过滤 | 性能 |
|------|--------|------|
| Intersects | bbox | 最快 |
| Within/Contains | bbox + 后过滤 | 中等 |
| Disjoint | 无 | 最慢（全表扫描） |

## 5. 连接池与批量写入（Phase 3）

### 5.1 GdbConnectionPool

```cpp
#include "connection_pool.h"

// 创建连接池（最多 4 个连接）
GdbConnectionInfo info;
info.setServer("/path/to/data.gdb");
GdbConnectionPool pool(info, 4);

// 获取连接
auto conn1 = pool.acquire();
std::cout << "活跃: " << pool.getActiveCount() << std::endl;  // 1
std::cout << "空闲: " << pool.getIdleCount() << std::endl;    // 0

// 使用连接
GdbDataset cities = conn1->getDatasets().get("cities");
GdbRecordset rs = cities.getRecordset();
while (rs.moveNext()) { /* ... */ }

// 归还连接
pool.release(std::move(conn1));
std::cout << "空闲: " << pool.getIdleCount() << std::endl;    // 1
std::cout << "活跃: " << pool.getActiveCount() << std::endl;  // 0
```

### 5.2 多线程并发读取

```cpp
#include <thread>
#include <vector>

GdbConnectionPool pool(info, 4);
std::vector<std::thread> threads;

for (int t = 0; t < 3; t++) {
    threads.emplace_back([&pool, t]() {
        // 每个线程 acquire 独立连接
        auto conn = pool.acquire();
        if (!conn) return;

        GdbDataset cities = conn->getDatasets().get("cities");
        GdbRecordset rs = cities.getRecordset();
        int count = 0;
        while (rs.moveNext()) count++;

        std::cout << "Thread " << t << " read " << count << " features" << std::endl;
        pool.release(std::move(conn));
    });
}

for (auto& th : threads) th.join();
```

### 5.3 GdbBatchWriter 批量写入

```cpp
#include "batch_writer.h"

auto conn = pool.acquire();
GdbDataset layer = conn->getDatasets().get("items");

// 批量大小 100，每 100 条自动 flush
GdbBatchWriter writer(layer, 100);

for (int i = 0; i < 500; i++) {
    GdbFeature feat;
    feat.setField("name", GdbField(std::string("item_" + std::to_string(i))));
    feat.setField("value", GdbField(i * 10));
    OGRPoint pt(i * 1.0, i * 2.0);
    feat.setGeometry(std::unique_ptr<OGRGeometry>(pt.clone()));

    if (!writer.addFeature(feat)) {
        std::cerr << "添加要素失败: " << writer.getLastError() << std::endl;
    }
}

// 提交剩余缓冲
size_t total = writer.commit();
std::cout << "共写入 " << total << " 条要素" << std::endl;

pool.release(std::move(conn));
```

### 5.4 多线程并发写入

```cpp
GdbConnectionPool pool(info, 4);
std::vector<std::thread> threads;

for (int t = 0; t < 3; t++) {
    threads.emplace_back([&pool, t]() {
        auto conn = pool.acquire();
        if (!conn) return;

        GdbDataset layer = conn->getDatasets().get("items");
        GdbBatchWriter writer(layer, 200);

        for (int i = t * 1000; i < (t + 1) * 1000; i++) {
            GdbFeature feat;
            feat.setField("thread_id", GdbField(t));
            feat.setField("index", GdbField(i));
            OGRPoint pt(i * 1.0, i * 2.0);
            feat.setGeometry(std::unique_ptr<OGRGeometry>(pt.clone()));
            writer.addFeature(feat);
        }

        writer.commit();
        pool.release(std::move(conn));
    });
}

for (auto& th : threads) th.join();
```

> **线程安全原则**：GdbConnectionPool 是整个组件库唯一线程安全的对象。所有视图对象（Datasets/Dataset/Recordset/BatchWriter）均不线程安全。多线程通过 Pool.acquire() 获取独立连接实现隔离，不需要内部加锁。
>
> **跨进程并发**：OpenFileGDB 不支持跨进程写锁。多进程并发写同一 `.gdb` 文件可能导致数据损坏，需业务层保证互斥。

## 6. 已知限制与注意事项

### 6.1 OpenFileGDB 驱动限制

| 限制 | 表现 | 应对 |
|------|------|------|
| 不支持原生事务 | StartTransaction 返回失败 | 组件不封装 begin()，BatchWriter 不调用事务 |
| 自动转换线/面几何 | wkbLineString→wkbMultiLineString, wkbPolygon→wkbMultiPolygon | 测试中接受两种类型 |
| Integer64 存为 Float64 | 读取时类型不匹配 | 用 Real 字段 + 容差比较 |
| 属性过滤有限 | SetAttributeFilter 支持程度有限 | 复杂条件在内存中过滤 |

### 6.2 OGRLayer 共享状态

OGRLayer 维护持久状态，需注意：

- **滤镜持久化**：`SetAttributeFilter()`/`SetSpatialFilter()` 设置在 Layer 上，不因新 GdbRecordset 而清除
- **共享游标**：`GetNextFeature()` 推进 Layer 级游标
- **应对**：组件已在 `getRecordset()` 和 `query()` 内部调用 `ResetReading()`

### 6.3 生命周期规则

```
GdbDatasource — 拥有 GDALDataset*（唯一所有者）
    └── GdbDatasets — 非拥有视图，持有 GdbErrorContext*（生命周期 ≤ datasource）
        └── GdbDataset — 非拥有视图，持有 GdbErrorContext*（生命周期 ≤ datasource）
            └── GdbRecordset — 非拥有视图，持有 GdbErrorContext*（生命周期 ≤ datasource）
```

视图对象的生命周期不得超过其 GdbDatasource。GdbDatasource 销毁后，所有派生的视图对象失效。
