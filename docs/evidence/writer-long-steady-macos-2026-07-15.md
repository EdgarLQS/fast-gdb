# Writer 30 分钟长稳 macOS 验收记录

- **日期**：2026-07-15
- **代码版本**：`26f112b`
- **环境**：macOS arm64、Apple M5、16 GiB、Clang 21.0、GDAL 3.13.0
- **入口**：`PerformanceBenchmarkFixture.W10_WriterLongSteady_100KCycles`

## 方法

先执行一次不计入结果的 100K 四字段 Polygon 预热，再在 1800 秒内重复以下闭环：删除上一临时 GDB、
用 GDAL 创建空 schema、fast-gdb 写入 100K 行并关闭、GDAL 重开校验总行数。每轮数据使用固定随机种子
42；任何写入或回读失败都会立即停止。RSS 增长从预热后开始计算，默认门槛 32 MiB。

测试进程运行 1800.729 秒（包含预热和 Google Test 开销），门禁内计时为 1800.176 秒。3281 轮均完成
GDAL 重开数量验证，没有发现累计内存增长、关闭失败或中途格式损坏。本结果只证明该固定 100K 重建
工作流在本机 30 分钟稳定，不代表并发写、非空追加、崩溃恢复或 35GB/5 亿级数据已验收。
