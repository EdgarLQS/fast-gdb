# GdbQuery 空间关系查询说明

## 背景

GDAL/OGRLayer 的 `SetSpatialFilter()` 仅支持 **bbox 相交（Intersects）** 预过滤。这是 GDAL 官方文档明确的行为：

> *"Only features that geometrically intersect the filter geometry will be returned. Currently this test may be inaccurately implemented, but it is guaranteed that **at least the envelope of the geometry is taken into account**."*

对于 `Contains`（包含）、`Within`（在...内）、`Disjoint`（不相交）等空间关系，GDAL 的 Layer 层不提供原生支持，必须在应用层通过后过滤实现。这也是开源界（Python GDAL Cookbook、GeoServer 等）的标准做法。

## GdbSpatialRelation 枚举

```cpp
enum class GdbSpatialRelation {
    Intersects,   // 相交（默认，驱动层 bbox 过滤）
    Contains,     // 包含（后过滤：filterGeom->Contains(featureGeom)）
    Within,       // 在...内（后过滤：featureGeom->Within(filterGeom)）
    Disjoint,     // 不相交（后过滤：filterGeom->Disjoint(featureGeom)）
};
```

## 实现策略

### 两层过滤架构

```
GdbDataset::query(q)
    ├── 第 1 层：OGRLayer SetSpatialFilter（bbox 预过滤，快速缩小候选集）
    │       └── Disjoint 时跳过（预过滤会排除目标，不能加速）
    │
    └── 第 2 层：GdbRecordset::moveNext()（几何关系后过滤）
            └── Intersects：直接使用 SetSpatialFilter 结果，无后过滤
            └── Contains/Within/Disjoint：逐要素检查 OGRGeometry 关系
```

### 性能特征

| 关系 | 预过滤 | 后过滤 | 性能 |
|------|--------|--------|------|
| Intersects | bbox（驱动层） | 无 | 最快 |
| Within | bbox（驱动层） | `geom->Within(filter)` | 中等 |
| Contains | bbox（驱动层） | `filter->Contains(geom)` | 中等 |
| Disjoint | **无** | `filter->Disjoint(geom)` | 最慢（全表扫描） |

**Disjoint 特殊处理**：不能用 bbox 预过滤，因为预过滤返回的是"相交的"要素，而我们需要的是"不相交的"。因此 Disjoint 需要遍历全部要素，性能最差。

### 过滤时机

后过滤在 `GdbRecordset::moveNext()` 中执行，每次获取到候选要素后：
1. 检查要素是否有几何（无几何时，Disjoint 视为匹配，其他跳过）
2. 调用 OGRGeometry 对应关系方法
3. 不匹配则销毁要素继续下一个

```cpp
// GdbRecordset::moveNext() 核心逻辑
while ((m_currentFeature = m_layer->GetNextFeature()) != nullptr) {
    const OGRGeometry* geom = m_currentFeature->GetGeometryRef();
    if (!geom) {
        if (m_spatialRelation == GdbSpatialRelation::Disjoint) break;
        continue;
    }
    bool match = false;
    switch (m_spatialRelation) {
        case GdbSpatialRelation::Contains:   match = m_spatialFilter->Contains(geom); break;
        case GdbSpatialRelation::Within:     match = geom->Within(m_spatialFilter); break;
        case GdbSpatialRelation::Disjoint:   match = m_spatialFilter->Disjoint(geom); break;
    }
    if (match) break;
}
```

## 使用示例

### 基本空间查询

```cpp
// 构建查询几何（珠三角 bbox）
OGRPolygon bbox;
OGRLinearRing ring;
ring.addPoint(112.0, 21.0);
ring.addPoint(115.0, 21.0);
ring.addPoint(115.0, 24.0);
ring.addPoint(112.0, 24.0);
ring.closeRings();
bbox.addRing(&ring);

// 默认 Intersects
GdbQuery q;
q.spatial(&bbox);
GdbRecordset rs = cities.query(q);
// rs 返回与 bbox 相交的所有要素
```

### 指定空间关系

```cpp
// Within：点在 bbox 内
GdbQuery q;
q.spatial(&bbox, GdbSpatialRelation::Within);

// Disjoint：不在 bbox 内的要素
GdbQuery q;
q.spatial(&bbox, GdbSpatialRelation::Disjoint);
```

### 空间 + 属性组合

```cpp
// 珠三角区域内 + 人口 > 1400万
GdbQuery q;
q.where("population > 14000000")
 .spatial(&bbox);
GdbRecordset rs = cities.query(q);
```

### 与 GdbQueryParameter 的对比

| 特性 | GdbQuery (链式) | GdbQueryParameter |
|------|-----------------|-------------------|
| 空间关系 | Intersects/Contains/Within/Disjoint | 仅 Intersects（SetSpatialFilter） |
| API 风格 | 链式 `q.spatial(geom, relation)` | 属性设置 `param.setSpatialFilter(geom)` |
| 后过滤 | 自动（moveNext 中） | 手动（遍历后自行检查） |
| 适用场景 | 快速查询 | 复杂过滤（结果字段控制等） |

## 已知限制

1. **OpenFileGDB 驱动不支持空间索引加速**：没有 `.spx` 文件时，bbox 过滤也是全表扫描
2. **Disjoint 无预过滤优化**：必须遍历全部要素
3. **OGRGeometry 空间关系方法依赖 GEOS 库**：GDAL 编译时未包含 GEOS 时，这些方法可能返回不准确的结果
4. **count() 方法同样受后过滤影响**：Disjoint 的 count 会遍历全部要素
