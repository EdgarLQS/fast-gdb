证据等级与 AI 审核清单

标签可以证明不能自动证明
EsriConfirmedArcGIS 产品语义、公开行为和兼容要求未公开的磁盘字节布局
GdalConfirmed指定 GDAL 版本的实现和测试行为Esri 官方规范或全部 ArcGIS 版本
FastGdbConfirmed当前分支实现、合同和测试仓库尚未覆盖的数据变体
DataObserved指定样本中的实际字节或行为所有版本和所有数据集
Inferred有证据支撑的工作假设稳定格式规则
Unknown诚实标出证据缺口任何实现承诺

审核 AI 方案的七问

  1. 它在讨论哪一层？是否把 API 现象误当成磁盘格式？
  2. 每个关键结论的证据标签是什么？版本和样本范围是什么？
  3. 是否混淆 FID、slot、record offset 和业务字段？
  4. 是否把 SPX/ATX 候选当成最终结果？
  5. 是否区分 Null、Empty、Unsupported、Degraded、Corrupt？
  6. 是否保留损坏输入、未知类型和未来版本的 fail-closed 路径？
  7. 测试是否有真实数据、合成边界、GDAL 对照和跳过项说明？
