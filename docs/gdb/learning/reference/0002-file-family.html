FileGDB 文件家族速查

内部编号不是业务名称。通常需要先解析系统 Catalog，再把逻辑图层映射到同编号的文件家族。

成员职责Reader 关注点
.gdbtableSchema、记录和字段/几何 payload边界检查、字段布局、记录解码
.gdbtablx逻辑 slot/FID 到记录 offset宽度、空洞、截断、计数上限
.spx空间索引候选页结构、BBox、排序、损坏回退
.atx属性索引候选字段类型、key 排序、NULL、表达式适用性
.freelistWriter 可复用的物理空闲区域解释碎片；不等于 FID 复用
timestamps目录级辅助状态不能替代完整源快照校验
锁文件ArcGIS/GDAL 编辑协调的一部分存在与否不构成 fast-gdb 并发读写保证
