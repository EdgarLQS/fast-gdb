# Teaching Notes

- 学习者对 FileGDB 从零开始，但具备 C++ 项目背景。
- 核心目标是概念和结构的完整理解，不以手工编码量衡量进度。
- AI 用于解释、追踪源码、提出方案和生成候选修改；学习者负责证据判断和最终审核。
- 每课先建立心智模型，再接触字节、源码和测试。
- 使用“掌握后推进”而不是固定 18 周；达到 Provisional 后解锁下一模块，完成 D+2、D+7、D+21 后才是 Mastered。
- 学习方式采用浏览器标准答案浏览、真实 CLI 实验和当前 Codex 对话口试，不制作预录视频，也不要求学习者自行绘图或手工解码。
- 原始进度保存在 `build/learning/`；只有长期掌握的非显然结论才进入 `learning-records/`。
- 高级数据集阶段以知识地图和边界为主，不宣称掌握未公开的二进制细节。
