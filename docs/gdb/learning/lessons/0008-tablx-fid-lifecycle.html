Week 08 · Identity and location

FID 说明“哪条”，TABLX 说明“在哪”

FID 与 SlotTABLX Offset删除、复用与 REPACK

把 FID、slot、offset 和物理空间拆开，是理解删除、稀疏标识、碎片和重打包的关键。

四个不同概念

概念职责
OID/FID对外或逻辑记录标识
slotTABLX 中的逻辑位置
record offsetGDBTABLE 中记录的字节位置
free regionWriter 可复用但当前不属于有效记录的物理空间
FID / slot ─→ TABLX entry ─→ 0: deleted or absent
                             └→ nonzero offset ─→ GDBTABLE record

TABLX 可能使用不同 offset 宽度。稀疏 FID 和 64 位 OID 不能由 32 位 API 静默截断。

AI 审核题

AI 为节省内存，只保留非零 offset 数组，并用数组下标作为 FID。

审核要点：这会压缩稀疏 slot，破坏 FID 对应关系。

闭卷复述

空间复用为什么不等于 FID 复用？

freelist 管理物理字节区域；FID 分配管理逻辑标识，二者是不同层。
