Week 02 · Bytes

字节不是知识点，是观察工具

不写解析器，只建立阅读二进制格式所需的最小语言：offset 告诉你去哪，length 告诉你读多少，encoding 告诉你怎样解释。

四个基本问题

问题典型答案
从哪里读？绝对或相对 offset
读多少？固定宽度、length 前缀或结束条件
怎样解释？小端整数、IEEE 754、VarUInt、UTF-8、UTF-16
怎样判断缺失？NULL bitmap、零 offset、标志位

最小编码模型

fixed integer: 4 bytes, little-endian
VarUInt:       7 data bits per byte + continuation bit
ZigZag:        signed integer → small unsigned integer
bitmap:        one bit answers one yes/no question
OLE Date:      floating-point days from an epoch

闭卷复述

为什么 offset 与 FID 不是同一个概念？

FID 是逻辑标识；offset 是文件位置。TABLX 才负责把逻辑 slot 映射到物理位置。

bitmap 的位数由什么决定？

由参与位图的逻辑字段集合决定，而不是简单等于所有字段数量。
