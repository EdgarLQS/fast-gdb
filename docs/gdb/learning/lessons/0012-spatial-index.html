Week 12 · SPX

空间索引负责缩小范围，不负责最终真相

SPX 的工作是快速产生可能相交的 FID。页面结构、网格编码和 BBox 都服务于候选过滤，精确谓词仍需真实几何。

B+ 树角色

query bbox
  → encode relevant spatial keys
  → branch pages choose child ranges
  → leaf pages return candidate FIDs
  → sort / unique / validate
  → read geometry and apply exact predicate
情况Reader 行为
SPX 有效使用候选集，再做最终判断
SPX 缺失回退到 BBox peek、内存索引或扫描
SPX 损坏明确诊断；只在合同允许时安全回退
候选为空是有效结果，不等于索引失败

闭卷复述

为什么候选集允许假阳性？

索引使用较粗的包围盒或网格表示以换取速度，候选只保证值得进一步检查。

损坏索引为何不能总是静默扫描？

调用者可能需要区分性能回退与数据完整性问题；合同还可能要求 fail closed。
