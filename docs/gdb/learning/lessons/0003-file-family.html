Week 03 · File family

一个逻辑表，对应一组物理文件

`.gdb` 是目录。内部编号把同一对象的数据、偏移、空间索引、属性索引和空闲空间组织成文件家族。

职责分工

文件回答的问题
.gdbtableSchema 和记录内容是什么？
.gdbtablx某个逻辑 slot 的记录位于哪里？
.spx哪些 FID 可能与空间范围相交？
.atx哪些 FID 可能满足属性比较？
.freelistWriter 可以复用哪些物理区域？
辅助文件版本、锁、边界或其他内部状态是什么？
目录盘点
find test_data/gdb/acceptance_metadata.gdb -maxdepth 1 -type f | sort
du -ah test_data/gdb/acceptance_metadata.gdb | sort -h | tail

任选一个编号，列出它拥有的文件。解释“文件缺失”可能代表不需要、未创建、损坏或版本差异，不能只给一种结论。

版本入口

ArcGIS 9、10+、不同 ArcGIS Pro 版本可能改变系统元数据、字段类型和 OID 能力；CDF/SDC 压缩还会改变可读边界。版本差异必须单独建矩阵，不能藏在通用解析逻辑中。

GdalConfirmedGDAL 文档明确列出 ArcGIS 版本、CDF/SDC 和 64 位 OID 等限制。DataObserved当前样本出现 .horizon 等辅助文件，其语义不能仅凭文件名推断。

AI 审核题

AI 说：“没有 `.spx` 说明图层损坏，应该拒绝打开。”

审核要点：空间索引可以缺失；Reader 应区分核心表损坏与可回退的可选索引缺失。

闭卷复述

一个逻辑对象可能有多个伴随文件，目录还包含系统表和辅助对象。
