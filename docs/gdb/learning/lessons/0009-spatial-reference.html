Week 09 · Precision grid

FileGDB 存的是网格整数，不只是浮点坐标

坐标解码必须和空间参考 descriptor 一起理解：origin 决定起点，scale 决定网格密度，resolution 与 tolerance 决定精度和空间行为。

四个量

WKID、LatestWKID 和 WKT 用于识别坐标参考系；下面的精度网格参数决定该参考系中的坐标怎样量化和存储。

量直觉
Origin整数网格的参考起点
Scale每个坐标单位包含多少整数格；通常与 resolution 互为倒数
Resolution可表达的网格步长
Tolerance高级空间行为使用的接近阈值，不等同于分辨率
Domain该精度网格能够安全覆盖的坐标范围
stored integer ── decode formula + origin/scale ──→ coordinate
XY / Z / M each has its own origin, scale and tolerance
坐标推导

从 Geometry descriptor 选一组 XY origin/scale，再选一个存储整数。先写公式和单位，再计算坐标。然后改变 scale，解释 resolution 和可覆盖 domain 如何变化。

EsriConfirmed空间参考、resolution、tolerance 和 domain 的产品含义。GdalConfirmedOpenFileGDB 文档公开 origin/scale/tolerance 选项及 domain 约束。具体几何编码公式仍需源码和数据交叉验证。

AI 审核题

AI 直接把 VarInt 解码结果转换成 double，未读取 geometry descriptor。

审核要点：缺少 origin/scale 无法得到真实坐标；Point、BBox 和 delta 序列还可能有不同细节。

闭卷复述

Scale 变大通常意味着什么？

网格更密、resolution 更小，但固定整数域能覆盖的现实坐标范围也会变化。

为什么 Feature Dataset 强调共享空间参考？

其中数据集需要在同一坐标、精度和容差框架下参与拓扑或网络等行为。
