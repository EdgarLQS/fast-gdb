Week 15 · Raster

Raster 不是“Geometry 字段的另一种值”

Raster 组成层次Raster 与 Mosaic Dataset能力分层与证据边界

Raster 数据集需要像元块、波段、NoData、统计值、金字塔、地理参考和可能的镶嵌管理结构。课程目标是理解组成和边界，不猜测未公开字节。

同时区分旧式 Raster Catalog 与现代 Mosaic Dataset：二者都可能通过目录记录组织多个影像，但能力和内部对象不能互相代替。

组成视图

Raster dataset
├─ pixel/block storage
├─ bands and pixel type
├─ georeferencing / spatial reference
├─ NoData / statistics / colormap
└─ pyramids / overviews

Mosaic dataset
├─ catalog-like records for source rasters
├─ footprints / boundaries / seamlines
├─ processing functions
└─ derived raster behavior
边界：能列出 Raster 相关系统对象、读取某个 Binary payload，或读取 footprint Feature，都不等于能重建 Raster 像元和 Mosaic 行为。
标准答案提示

学习台中的 M15 标准答案直接给出 Raster/Mosaic 的组成图和 Discovery、Metadata、Pixels、Derived、Behavior 能力表；无需自行列矩阵。

EsriConfirmedFileGDB 可包含 Raster/Mosaic 等数据集。GdalConfirmedOpenFileGDB 当前文档列出 Raster 能力和版本。Unknown课程不把公开驱动能力反推为完整 Esri 私有内部规范。

AI 审核题

AI 在 FieldType 中看到 Raster，于是复用普通 Binary 字段逻辑并宣称支持 Raster Dataset。

审核要点：字段 payload 只是组成部分；像元块、波段、金字塔和数据集元数据仍未被证明。

闭卷复述

为什么 Raster 支持必须分层声明？

列举数据集、读取元数据、读取像元、应用函数和完整 Mosaic 行为是不同能力。
