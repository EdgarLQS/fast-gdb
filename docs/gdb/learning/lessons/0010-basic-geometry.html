审核要点：part 是 ring，不一定都是 exterior；必须根据拓扑组织 hole 和 MultiPolygon。

闭卷复述

BBox 为什么常放在完整坐标前？

可以先做快速范围判断，避免为明显不相交的几何解码全部坐标。

Delta 编码带来什么要求？

当前坐标依赖前一个坐标，必须保持顺序和足够整数精度，截断会污染后续点。
