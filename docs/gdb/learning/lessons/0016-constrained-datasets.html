Week 16 · Rules and derived state

基础 Feature 可读，不代表约束型数据集可用

参与要素与数据集定义规则、派生结构与脏区Topology、Terrain 与 Network 边界

Topology、Terrain、TIN 和 Network Dataset 都在基础要素之上叠加规则、参与者、派生结构和维护状态。

共同模式

participating feature classes
  + dataset definition
  + rules / roles / connectivity
  + derived index or graph
  + dirty areas（脏区）/ validation state
  = advanced dataset behavior
数据集核心问题
Topology哪些类参与、有哪些规则、哪些区域未验证？
Terrain/TIN哪些点线面参与、金字塔/三角网如何派生？
Network Dataset连通性、成本、限制、转向和图结构是什么？
Geometric Network旧式网络的边/点角色与连通关系如何表示？
标准答案提示

学习台中的 M16 标准答案直接展示基础 Feature → Definition → Rules → Derived state 四层关系，以及“只读底层表是否足够”的能力判断；无需自行绘图。

EsriConfirmed官方文档确认这些数据集及其行为概念。DataObserved只有拿到对应真实 GDB 才能确认系统对象和物理表。Unknown缺少源码/样本时不描述内部二进制。

AI 审核题

AI 能读网络参与的道路和节点图层，因此宣布支持 Network Dataset。

审核要点：尚未证明连通性图、成本、限制、转向、层级和网络构建状态。

闭卷复述

派生结构为什么不能从“表可读”推出？

派生结构可能依赖多个参与表、规则和构建版本，其一致性不是单表记录能够证明的。
