### 步骤 2：添加覆盖率脚本

创建 `scripts/coverage.sh`：

```bash
#!/bin/bash
set -e
cd "$(dirname "$0")/.."
mkdir -p build_coverage && cd build_coverage
cmake .. -DENABLE_COVERAGE=ON
make -j$(sysctl -n hw.ncpu)
# 运行所有 explorgdb 测试
./bin/gdb_tutorial_test_runner --gtest_filter='explorgdb*'
# 生成覆盖率报告
lcov --capture --directory . --output-file coverage.info --ignore-errors mismatch
lcov --remove coverage.info '/usr/*' '*/gtest/*' '*/test_*' --output-file coverage.info
genhtml coverage.info --output-directory coverage_report --title "explorgdb Coverage"
echo "✅ 覆盖率报告: build_coverage/coverage_report/index.html"
open coverage_report/index.html 2>/dev/null || true
```

## 任务二：peek_blob 性能优化 — mmap 方案（待启动）

### 瓶颈分析

- `peek_geometry_blob()` 每次调用 2 次 pread()（4 字节头 + ~140 字节数据）
- 10M Large 查询：8.17M 次 peek × 2 = **16.3M 次系统调用**
- 总耗时 5054ms，与 16.3M × 0.31μs 估算完美吻合
- 对比：顺序读 1.18GB 仅需 <100ms → **系统调用开销导致慢 ~50 倍**

### 推荐：mmap

将 `read_at()` 从 pread 改为 memcpy（mmap 映射后）。

**改动量**：~30 行，仅 `gdb_table.h` + `gdb_table.cpp`

### mmap 的缺点（完整分析）

| 缺点 | 严重度 | 对我们项目的影响 |
|------|:------:|----------------|
| **page cache 污染** — 大文件 mmap 挤占其他进程缓存 | 中 | 10M 文件 1.4GB 会占满 page cache。但场景是专用 benchmark，影响有限 |
| **随机访问不如 pread** — 内核可能预读无用页面 | 低 | FID 已排序，偏移几乎连续，不是随机访问 |
| **小文件 setup 开销** — mmap 系统调用 + TLB 刷新 | 低 | 小数据集 2MB，mmap setup ~1ms 可忽略 |
| **平台差异** — macOS/Linux 的 madvise 行为不同 | 低 | macOS ARM64 完全支持 |
| **不能增量释放** — 整个虚拟地址区间被占用 | 低 | 64 位系统 256TB 虚拟地址，1.4GB 微不足道 |
| **调试困难** — 段错误比 pread 返回错误更难排查 | 中 | 需做好边界检查 |
| **文件锁定** — 映射期间文件被删除会 SIGBUS | 极低 | .gdbtable 是只读数据文件 |

**结论**：在我们的场景下（大文件、近似顺序访问、只读、专用 benchmark），mmap 缺点影响都很小。

### 实施细节

**`gdb_table.h`** — 新增成员：
```cpp
uint8_t* mapped_data_ = nullptr;  // mmap 映射基址
```

**`gdb_table.cpp`** — `open()` 添加 mmap：
```cpp
mapped_data_ = static_cast<uint8_t*>(
    mmap(nullptr, file_size_, PROT_READ, MAP_PRIVATE, fd_, 0));
if (mapped_data_ == MAP_FAILED) mapped_data_ = nullptr;  // 降级到 pread
madvise(mapped_data_, file_size_, MADV_SEQUENTIAL);
```

**`read_at()`** — 优先用 memcpy：
```cpp
bool GdbTableParser::read_at(uint64_t offset, void* buffer, size_t size) const {
    if (mapped_data_ && offset + size <= file_size_) {
        std::memcpy(buffer, mapped_data_ + offset, size);
        return true;
    }
    // fallback: pread
    ssize_t n = pread(fd_, buffer, size, static_cast<off_t>(offset));
    return n == static_cast<ssize_t>(size);
}
```

**析构** — 添加 munmap：
```cpp
if (mapped_data_) munmap(mapped_data_, file_size_);
```

| 总查询耗时 | 6121ms | ~1200ms | **5×** |
