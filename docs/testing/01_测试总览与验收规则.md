# 测试总览与验收规则

本目录定义 fast-gdb 的测试入口、覆盖范围和发布判定。代码侧快速索引见 [`tests/INDEX.md`](../../tests/INDEX.md)。

## 结果分类

- `PASS`：测试已执行且断言通过。
- `SKIPPED`：环境或真实数据缺失，不能作为验收通过。
- 基础设施失败：构建、运行器或环境异常，需单独修复。
- characterization：记录现象，不形成产品支持承诺。

并发读写观测不得解释为一致性保证；`UnverifiedConcurrentRead` 永远不是 verified 正确性结果。

## 发布门禁

发布至少执行 Geometry、Reader、GDAL 边界和安装 consumer 门禁；真实数据和性能门禁必须附带环境、数据 manifest 与证据文件。
