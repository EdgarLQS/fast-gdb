## 1. 建议审核顺序

### 第一组：公开契约

文件：

1. `query_engine.h`
2. `tests/edgar/explorgdb/reader/test_feature_cursor.cpp`
3. `tests/package_consumer/main.cpp`

确认：

- `SpatialWhere` 仍只追加在 QueryKind 末尾；
- `QueryFeature` 只包含 FID、FeatureRecord、GeometryValue；
- FeatureCursor 可移动、不可复制；
- QueryEngine 不可复制、可移动构造但不可移动赋值；cursor 所需控制块与 table 对象地址稳定，移动后的源 engine 安全不可用；
- PImpl 不暴露 parser、FieldRef 或 WHERE 内部类型；
- `move_to(uint32_t)` 明确按零基 FID，而不是结果序号；
- package consumer 只使用公开安装头。

### 第二组：联合查询

文件：

1. `query_engine.cpp`
2. `query_engine_combined.cpp`
3. `query_where_internal.h/.cpp`
4. `gdb_indexes.h/.cpp`
5. `gdb_attribute_index.h/.cpp`

确认：

- bbox 和 WHERE 非法时明确返回 invalid；
- `.spx/.atx` 都只提供候选；
- `.atx` 候选排序、去重并最终完整 WHERE；
- 非 BMP、`!=`、函数索引和不明确编码安全回退；
- 损坏 `.atx` 不得解释为合法零命中；
- 旧 `WhereClause` execution path 和语义未改变。

### 第三组：FeatureCursor 状态机

文件：

1. `feature_cursor.cpp`
2. `query_engine.cpp`
3. `query_engine_geometry.cpp`

确认：

- candidate 模式只保存 FID vector；
- SequentialScan 不调用全表 query，不物化全表 FID；
- `next()` 使用局部 candidate，失败不半更新输出；
- Ready、Exhausted、Failed、moved-from 的 `done/error` 组合正确；
- 首次失败锁定；
- 正常耗尽和失败都释放 engine lease；
- cursor generation 防止迟到析构清除新 cursor；
- open generation 防止 engine 重开后复用旧计划；
- engine 重开时空间索引缓存被重置；
- 活动 cursor 期间公开 engine 读入口按合同拒绝；
- `query_engine_geometry.cpp` 只增加 guard，没有丢失原自适应 planner。

### 第四组：`move_to(fid)`

确认：

- candidate 模式使用 `lower_bound`；
- sequential 模式从 target 槽开始；
- 删除槽被跳过；
- 不满足过滤的 FID 跳到下一个匹配 FID；
- 向前、向后和 `move_to(0)` rewind 均可用；
- target 后无结果时进入正常 Exhausted；
- EOF 后 reacquire 必须在任何 parser/tablx 访问之前；
- 其他 cursor 活动时旧 cursor 不得读取 parser；
- engine 重开后旧 cursor 必须 Failed；
- Failed 和 moved-from 不得重新定位。

## 2. P0 检查点

任何一项成立都应阻断合并：

- 损坏索引导致假空集或漏 FID；
- 未执行精确空间判断或完整 WHERE；
- `next()==false` 的错误被表现为正常 EOF；
- `move_to` 返回 target 之前的 FID 或不满足查询的 FID；
- SequentialScan 先物化全部 Feature 或全表 FID；
- move/析构/reacquire 错误释放其他 cursor 的 engine lease；
- engine reopen 后旧 cursor 读取新 parser；
- 完整字段、NULL、Binary 或 WKB 与 GDAL 不一致；
- 输出参数在失败时被部分覆盖；
- 空间 planner 因 cursor guard 被意外替换；
- 安装面暴露内部类型或 package consumer 无法链接。

## 3. P1 检查点

- 公共头依赖传递 include；
- QueryEngine 移动后 cursor 控制块或 table 指针失效，或 moved-from engine 发生崩溃；
- EOF 后 `move_to` 在取得 lease 前访问 parser；
- engine reopen 保留旧 `.spx` parser；
- ObjectID-only 行字段数量不完整；
- 无几何或 NULL geometry 被误报为失败；
- cursor query_result 重复保存 ReadByFid 完整 record；
- 旧 WHERE execution path 被改变；
- 测试共享固定临时目录；
- GDAL API 使用错误字段参数；
- fatal GTest assertion 出现在非 void helper；
- benchmark 只比较数量或硬编码 correct；
- fallback_reason、execution_path 和 state 不一致。
