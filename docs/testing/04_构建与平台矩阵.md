# 构建与平台矩阵

当前本地验证基线为 macOS + GDAL 3.9.3。该版本是可用基线，不强制要求 GDAL 3.13。

| 维度 | 当前状态 | 说明 |
|---|---|---|
| GDAL 3.9.3 | 当前基线 | 本地构建、测试和 package consumer |
| 其他 GDAL 版本 | 后续验收 | 用于兼容性扩展，不改变当前合同 |
| macOS | 当前验证 | 主要本地环境 |
| Linux/Windows | 后续验收 | 需独立环境和证据 |
| Adaptive ON/OFF | 已覆盖 | OFF 配置保持纯 Reader 边界 |

平台或版本未执行时标记为 `SKIPPED`，不得写成通过。
