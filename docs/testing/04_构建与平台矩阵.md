# 构建与平台矩阵

当前本地验证基线为 macOS + GDAL 3.13.0。其它 GDAL 版本需单独验证。

| 维度 | 当前状态 | 说明 |
|---|---|---|
| GDAL 3.13.0 | 当前基线 | 本地构建、测试和 package consumer |
| 其他 GDAL 版本 | 后续验收 | 用于兼容性扩展，不改变当前合同 |
| macOS | 当前验证 | 主要本地环境 |
| Linux/Windows | 后续验收 | 需独立环境和证据 |
| Adaptive ON/OFF | 已覆盖 | OFF 配置保持纯 Reader 边界 |
| 统一 facade / FastFileGDB | macOS + GDAL 3.13 已通过 | 其它 GDAL/平台仍需矩阵证据 |
| S3 / `/vsis3/` | Experimental / Unverified | 需要凭据、对象布局和远程 characterization |

## 安装 consumer

先分别生成安装前缀。`linear` 的构建必须关闭 GDAL；`adaptive` 的构建必须打开
GDAL 和 Adaptive：

```bash
cmake -S . -B build-linear -DFAST_GDB_WITH_GDAL=OFF \
  -DFAST_GDB_BUILD_ADAPTIVE_READER=OFF \
  -DCMAKE_INSTALL_PREFIX="$PWD/build-linear/install"
cmake --build build-linear --parallel
cmake --install build-linear

cmake -S . -B build-adaptive -DFAST_GDB_WITH_GDAL=ON \
  -DFAST_GDB_BUILD_ADAPTIVE_READER=ON \
  -DCMAKE_INSTALL_PREFIX="$PWD/build-adaptive/install"
cmake --build build-adaptive --parallel
cmake --install build-adaptive
```

安装验收再分别运行 consumer 目标：

```bash
cmake -S tests/package_consumer -B build-consumer-linear \
  -DFAST_GDB_CONSUMER_TARGET=linear \
  -DCMAKE_PREFIX_PATH="$PWD/build-linear/install"
cmake --build build-consumer-linear --parallel
ctest --test-dir build-consumer-linear --output-on-failure
```

`hybrid` 和 `unified` 使用包含 GDAL 的安装前缀，`adaptive` 使用
`-DFAST_GDB_CONSUMER_TARGET=adaptive` 和 `FAST_GDB_BUILD_ADAPTIVE_READER=ON`
的安装前缀。统一入口使用 `-DFAST_GDB_CONSUMER_TARGET=unified`。`linear` 的
consumer 必须在 GDAL 关闭的构建中通过；四种 target
都注册了 `fast_gdb_package_consumer` CTest 测试，且不包含 Writer。

## Sanitizer 与并发入口

在支持相应 sanitizer 的工具链上，可使用独立构建目录：

```bash
cmake -S . -B build-asan-ubsan -G Ninja \
  -DFAST_GDB_WITH_GDAL=ON \
  -DFAST_GDB_BUILD_ADAPTIVE_READER=ON \
  -DCMAKE_CXX_FLAGS="-fsanitize=address,undefined -fno-omit-frame-pointer" \
  -DCMAKE_EXE_LINKER_FLAGS="-fsanitize=address,undefined"
cmake --build build-asan-ubsan --parallel
ctest --test-dir build-asan-ubsan --output-on-failure
```

ThreadSanitizer 入口：

```bash
cmake -S . -B build-tsan -G Ninja \
  -DFAST_GDB_WITH_GDAL=ON \
  -DFAST_GDB_BUILD_ADAPTIVE_READER=ON \
  -DCMAKE_CXX_FLAGS="-fsanitize=thread -fno-omit-frame-pointer" \
  -DCMAKE_EXE_LINKER_FLAGS="-fsanitize=thread"
cmake --build build-tsan --target gdb_tutorial_test_runner \
  fast_gdb_adaptive_reader_test_runner --parallel
```

macOS、Windows 或特定编译器不支持这些 flags 时记为 `SKIPPED`，不能把普通
测试结果当作 sanitizer 证据。独立 Reader 并发测试名称为
`ReaderConcurrencyTest.IndependentReadersReturnIdenticalFeatureDigests`；它不测试
共享 `QueryEngine`。

平台或版本未执行时标记为 `SKIPPED`，不得写成通过。

统一入口的持续集成入口为：

- `.github/workflows/unified-routing.yml`：Linux GDAL 3.9–3.13，以及 macOS/Windows
  GDAL 3.13 的 facade、plugin、build-ID 和安装 consumer；
- `.github/workflows/s3-characterization.yml`：显式输入版本化 AWS S3 fixture 后执行
  真实 OpenFileGDB 读取；没有 fixture 时不产生远程支持证据。

2026-07-31 本地 macOS/AppleClang 已通过 GDAL 3.13 的 478 项全量普通测试、
GDAL 3.9.3 的 28 项统一入口定向测试、GDAL OFF 的 117 项测试，以及统一入口的
ASan/UBSan 和 TSan 各 28 项定向测试；GDAL 3.10–3.12 和跨平台结果仍须以 CI
实际运行结果为准。
