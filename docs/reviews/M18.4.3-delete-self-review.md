# M18.4.3 Delete 自我代码审查

- 日期：2026-07-16
- 分支：`codex/m18-1-macos-test-contract-ci`
- 结论：Request Changes（待当前 macOS 证据）

## 审查范围

`WriterDeleteSession`、稳定安装面、`writer-delete-macos-v1`、Google Test、专用 workflow、发布/回滚和已知限制。

## 已确认设计

- 完整同级 staging 副本；
- 单 Writer、one-shot 会话；
- 不存在 FID 和重复删除在发布前失败；
- 未删除 FID 不变，删除 FID 不复用；
- 每次删除立即确认 FID 不可读；
- commit 重开逐个确认删除 FID 不存在，并核对最终记录数；
- 非空结果重新获取范围；全删允许空表；
- 源指纹变化阻止发布；
- source→backup、staging→source，第二步失败回滚；
- abort/析构清理 staging，保留源 GDB。

## 自审发现

### Major 1：合同与 Google Test 命名不一致

初始 manifest 使用 `WriterDeleteSessionTest.*`，实际 fixture 为 `WriterDeleteFixture.*`，会导致 schema-v2 runner 零匹配失败。已修复为精确过滤器。

### Major 2：索引验收不能只检查文件存在

删除可能留下索引文件但产生陈旧命中。测试必须同时执行属性过滤和空间过滤，确认删除记录不再命中。已加入 `WriterDeleteIndexTest_NoStaleHitsAfterDelete`。

### Major 3：全删空表范围语义

空图层没有有效 extent，不能要求 `GetExtent` 成功。实现只对非空结果强制范围重算；全删以记录数为零和所有删除 FID 不可读为验收标准。

## 尚未覆盖的风险

- 没有真实 macOS 编译、运行和索引 artifact；
- 没有进程中止故障注入；
- 没有跨平台文件锁与发布语义；
- 没有原地 freelist 维护和 FID 空洞复用；
- 当前索引验证依赖 GDAL 查询语义，仍需真实 runner 证明。

## 合并建议

保持 Draft 和 Request Changes。只有 `writer-delete-macos-v1` required 场景连续三次通过、GDAL 安装消费成功、索引查询无陈旧命中后，才能把 ADR-005 改为 Accepted。
