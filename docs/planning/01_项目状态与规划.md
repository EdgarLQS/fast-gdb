## 1. 当前结论

| 模块 | 当前状态 | 结论 |
|------|:---:|------|
| `usegdal` 高层组件 | ✅ | 既定 Phase 1A-3 已实现 |
| `explorgdb reader` v2 | 🧪 | 常规只读主路径已实现并通过本地自动化；真实样本验收未完成 |
| `explorgdb writer` | ⚠️ | 主数据直写已实现；系统表同步未完成 |

reader v2 的边界是：

> 支持常规 FileGDB 只读、元数据和查询；不能完整表达的数据必须明确降级或返回不支持。

曲线标准输出、完整 SQL、重投影、Raster 像素和完整 MultiPatch 表面语义不属于 v2 完成范围。

## 3. reader v2 已完成能力

- `.gdbtable` / `.gdbtablx`、`.gdbindexes`、`.spx`、`.atx` 读取。
- nullable bitmap 旧记录兼容。
- DateTimeWithOffset 10 字节物理跳过。
- CatalogResolver、SRS、domain、Metadata item、Feature Dataset、relationship metadata。
- QueryEngine：FID、顺序扫描、bbox、属性索引和 WHERE 子集。
- GeneralPolyline / GeneralPolygon Curve flag/header 修正。
- `nCurves > 0` 明确 `UNSUPPORTED_CURVE_GEOMETRY`。
- 曲线空间过滤 fail closed，并通过 `fallback_reason` 说明记录被跳过。
- Raster 字段 degraded 标记。
- MultiPatch capability 已从 supported 改为 degraded。

## 4. v2 仍有的发布边界

| 能力 | 状态 | 当前边界 |
|------|:---:|----------|
| 常规 Point/MultiPoint/Polyline/Polygon | 🧪 | 自动化通过，真实样本未验收 |
| GeneralPolyline / GeneralPolygon | 🧪 | header 和合成测试完成，真实样本未验收 |
| MultiPatch / GeneralMultiPatch | ⚠️ | 坐标可输出，但 part type 和完整拓扑不保留 |
| DateTimeWithOffset | ⚠️ | 物理读取安全；offset 未独立暴露 |
| CircularArc / Bezier / EllipticArc | ❌ | 当前明确 unsupported |
| Raster 像素、Annotation、Dimension | ❌ | 当前不支持 |
| 完整 SQL / JOIN / 聚合 / 重投影 | ❌ | 不在 reader v2 范围 |

## 5. 后续统一进入 v3

新的执行入口为 [10_fast-gdb-v3几何正确性与真实数据计划.md](10_fast-gdb-v3几何正确性与真实数据计划.md)。

v3 P0：

1. GeneralPoint / GeneralMultiPoint 完整 decode 接入。
2. MultiPoint / GeneralMultiPoint `peek_bbox` header 修正。
3. Point decode、peek、空间过滤统一 `(raw - 1) / scale + origin`。
4. Curve flag 置位但 `nCurves == 0` 时三条路径保持一致。
5. 普通真实 FileGDB 和真实曲线 FileGDB 回归。

v3 P1：

- MultiPatch 保持 degraded 并补真实样本，或独立实现完整 part type 语义。
- 曲线标准输出仅在独立立项时恢复。

## 6. reader 范围外待办

- writer 系统表更新和 GDAL 兼容写入。
- 覆盖率提升。
- SIMD、多线程、零拷贝 WKT 等可选优化。
- 完整 OGRLayer / GDAL SQL 兼容。
