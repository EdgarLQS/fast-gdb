## 2. Writer 产品决策

### 唯一公共面

- `fast_gdb::writer`；
- `<versioned_gdb_store.h>`；
- `<versioned_gdb_validator.h>`。

### 已删除

- `fast_gdb::writer_legacy`；
- WriterSession 公共头；
- Append/Update/Delete/Transaction 公共头；
- 旧 recovery/index 公共头；
- 直接 source 发布协议；
- 旧 package consumer 和 workflow；
- 兼容期与迁移承诺。

### 当前能力

- immutable generation；
- Reader snapshot lease；
- 单 Writer 门禁；
- macOS/Linux CoW 优先和完整复制回退；
- 强制 reopen validator；
- atomic CURRENT；
- durable/not-published/uncertain 三态；
- crash cleanup、recover 和旧 generation GC。

VersionedGdbStore 不提供字段级编辑 DSL。调用方使用内部编辑器或 GDAL 修改 `working_path()`。

## 3. Reader 发布边界

| 能力 | 状态 | 边界 |
|---|:---:|---|
| Point/MultiPoint/Polyline/Polygon、Z/M/ZM | ✅ | 既有读取、WKB 和空间判断 |
| CircularArc / Bezier / EllipticArc | ✅/⚠️ | 纯 C++ 线性化和 Hybrid 策略 |
| MultiPatch / GeneralMultiPatch | ⚠️ | 不保留完整表面语义 |
| DateTimeWithOffset | ✅ | 值与 offset 独立暴露 |
| bbox + WHERE | 分支本地通过 | 最终执行精确复核 |
| full-feature cursor | 分支本地通过 | 完整字段 + GeometryValue |
| 35GB/5 亿级性能 | 未验收 | 不可由小规模结果外推 |

## 4. Writer 正式验收门禁

必须取得：

1. GDAL OFF Release + 完整 versioned store tests；
2. 安装后 writer package consumer；
3. macOS/APFS clonefile 和 full-copy fallback；
4. Linux reflink/非 reflink；
5. Windows full-copy、路径大小写门禁和 `MoveFileExW`；
6. Reader 跨发布并发矩阵；
7. ENOSPC、file/directory fsync、generation promote、CURRENT replace 和 root barrier 故障注入；
8. 真实 FileGDB record/FID/geometry/spx/atx validator；
9. 可下载、绑定当前 SHA 的 GitHub Actions artifacts。

## 5. 明确不规划

- 恢复旧 Writer API；
- 兼容 target 或别名；
- 内建字段级 Append/Update/Delete；
- schema migration；
- savepoint、嵌套、跨 GDB 或分布式事务；
- 跨进程锁或租约；
- 多 Writer；
- S3、对象存储或跨主机一致性；
- 原生曲线/MultiPatch 写入；
- FID 空洞复用；
- 自动空间预留和配额管理。
