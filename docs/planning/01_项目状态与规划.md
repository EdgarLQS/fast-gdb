## 2. 当前发布边界

| 能力 | 状态 | 边界 |
|---|:---:|---|
| Point/MultiPoint/Polyline/Polygon、Z/M/ZM | ✅ | 在既有声明数据和自动化范围内完成读取、WKB 和空间判断验收 |
| CircularArc / Bezier / EllipticArc | ✅ | 纯 C++ 默认线性化，Hybrid 可显式 GDAL 回退 |
| 原生 curve WKB | ⚠️ | 仅 GDAL Hybrid 显式模式，不是默认契约 |
| MultiPatch / GeneralMultiPatch | ⚠️ | 不保留完整 part type 和表面拓扑 |
| DateTimeWithOffset | ✅ | 日期值与 offset 独立暴露并覆盖既有读写回归 |
| Raster、Annotation、Dimension | ❌ | 当前不支持 |
| 完整 SQL / JOIN / 聚合 / 重投影 | ❌ | 不在 Reader 当前范围 |
| WHERE 子集 | ✅ | 支持比较、AND、OR、IN 和括号；不是完整 SQL |
| bbox + WHERE 联合查询 | 分支待审 | `QueryKind::SpatialWhere` 已在当前分支实现；只承诺 bbox 与现有 WHERE 子集，未进入正式发布声明 |
| Writer 空 schema、Append、Update、Delete、Transaction/Recovery | ✅/⚠️ | 既有实现边界保持不变；本分支不修改 Writer |
| 35GB/5 亿级真实性能 | 未验收 | 现有结果是受控 1K–10M 基准，不构成生产承诺 |

普通几何使用纯 C++ 主路径；正式输出和精确空间判断共享 `GeometryModel`。不能可靠表达的记录必须返回明确状态，或由显式 Hybrid 策略回退 GDAL。
