## U-401 ENOSPC

分别在以下阶段注入：

- clone/full copy；
- working 修改；
- file sync；
- directory sync；
- generation promote；
- CURRENT 临时文件；
- CURRENT replace；
- store root barrier。

完成判据：空间不足不删除或覆盖 CURRENT generation，Reader 继续读取完整旧版。

## U-402 Crash-phase 恢复

分别在以下边界终止并重启：

- work 创建中；
- validator 前后；
- generation rename 前后；
- CURRENT.tmp 写入后；
- CURRENT replace 前后；
- root barrier 前后；
- old generation GC 前后。

恢复后 CURRENT 必须指向完整 generation，或明确 fail closed。

## U-403 Durability uncertainty

- 强制 CURRENT replace 成功、root sync 失败；
- `publish()==false` 且 `published()==true`；
- 状态为 `PublishedDurabilityUncertain`；
- 新旧 generation 保留；
- 新 Writer 被拒绝；
- Reader 释放不触发 GC；
- 无 Reader/Writer 后 recover 成功并恢复 GC。
