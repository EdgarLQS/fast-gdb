## 1. 目标与成功标准

在 `QueryEngine` 中提供单次空间与属性联合查询入口。调用方只提供 bbox 和现有 WHERE 子集，不再自行执行空间查询、属性查询并求 FID 交集。

成功标准：

1. 最终结果等于“精确空间相交 FID 集 ∩ 完整 WHERE 命中 FID 集”；
2. Point、MultiPoint、Polyline、Polygon 以及 Z/M/ZM 保持既有精确空间语义；
3. 单个可证明安全的比较同时利用 `.spx` 和 `.atx`；
4. 复合 WHERE、缺索引、损坏索引或不安全索引编码只在精确空间命中行上求值；
5. `.atx` 仅产生候选，最终必须执行完整 WHERE 复核；
6. 最终 FID 零基、升序、唯一，并与 GDAL 联合过滤完整 FID 向量一致；
7. 既有 `SpatialBbox`、属性查询和 `WhereClause` 语义保持兼容；
8. 内部 parser 不进入安装面；
9. 实际构建、CTest、consumer 和性能证据齐全后才能 Accepted。

## 2. GDAL OpenFileGDB 参考实现

GDAL OpenFileGDB 的联合查询核心流程：

1. 空间过滤构建空间索引迭代器；
2. 属性表达式尝试构建属性索引迭代器；
3. 两种迭代器同时可用时执行有序 FID 交集；
4. 候选仍经过精确几何判断；
5. 属性索引不足以证明完整表达式时仍执行属性表达式复核。

参考源码入口：

- `ogr/ogrsf_frmts/openfilegdb/ogropenfilegdblayer.cpp`
  - `SetAttributeFilter()`
  - `BuildIteratorFromExprNode()`
  - `BuildCombinedIterator()`
  - `GetNextFeature()`
- `ogr/ogrsf_frmts/openfilegdb/filegdbindex.cpp`
  - `FileGDBIterator::BuildAnd()`
  - `FileGDBIterator::BuildOr()`

fast-gdb 首版采用更保守的候选规则：

- 所有 `.atx` 路径都执行完整 WHERE 复核；
- 字符串只对当前可证明安全的 `=` 和 `>=` 使用候选；
- 非 BMP 字符串回退，避免 surrogate pair 解码造成假阴性；
- `!=` 回退，避免 NaN 比较造成候选不完备；
- Int16、Float32、Int64 等不能由当前 trailer 唯一确定物理语义的编码不进入快速路径；
- `LOWER(field)` 和其他函数索引只用于字段关联，不用于直接比较快速路径；
- 复合 `AND`、`OR`、`IN` 首版不构造布尔索引计划。

## 3. 公开接口

`SpatialWhere` 追加到枚举末尾：

```cpp
enum class QueryKind {
    ReadByFid,
    SequentialScan,
    SpatialBbox,
    AttributeDouble,
    AttributeString,
    WhereClause,
    SpatialWhere
};
```

请求复用已有 bbox 和 `where_clause`：

```cpp
QueryRequest request;
request.kind = QueryKind::SpatialWhere;
request.xmin = 0.0;
request.ymin = 0.0;
request.xmax = 10.0;
request.ymax = 10.0;
request.where_clause = "population >= 1000 AND category = 'A'";

QueryResult result = engine.query(request);
```

执行路径：

- `spatial-where:spx+atx`；
- `spatial-where:spatial-candidates`；
- `spatial-where:sequential`；
- `spatial-where:invalid`。

`QueryResult` 增加 `CombinedQueryMetrics`，记录空间候选、精确空间命中、属性候选、WHERE 复核数、最终命中、阶段耗时和索引使用情况。指标只用于诊断，不改变查询语义。

### 4.2 字段到 `.atx` 的映射

```text
WHERE 字段
  -> .gdbindexes 原始索引表达式
  -> 字段关联和直接表达式判定
  -> IndexEntry.name
  -> aXXXXXXXX.<index-name>.atx
```

不猜测索引名等于字段名，不把函数索引误当裸字段索引。

### 4.3 稀疏候选字段扫描

新增 `GdbTableParser::scan_field_candidates()`：

- 根据 `.gdbtablx` 获取候选 FID 物理偏移；
- 按物理偏移读取；
- mmap 路径提供回调期零拷贝 `FieldRef`；
- fd 路径复用行缓冲；
- 复用 nullable bitmap 和字段物理布局；
- 能穿过 Geometry、Raster、UUID、Binary、DateTimeWithOffset 等非目标列；
- 扫描失败时回退 `read_record_by_fid()`；
- 最终恢复数值 FID 升序。

### 4.4 联合执行

`QueryEngine::query_spatial_where()`：

1. 校验 bbox；
2. 编译并绑定 WHERE；
3. 调用 `query_bbox_unified()` 得到精确空间命中；
4. 空间空集直接返回；
5. 单个安全比较解析 `.gdbindexes` 与 `.atx`；
6. `.atx` 候选排序、去重；
7. 与精确空间 FID 线性交集；
8. 对交集候选执行完整 WHERE 复核；
9. 缺失、损坏或不安全 `.atx` 回退到精确空间命中行求值；
10. 最终 FID 排序、去重并写入联合指标。

### 4.5 `.atx` fail-closed

三轮自审后增加：

- 文件长度、`streamoff`、`size_t`、`streamsize` 边界；
- 页面区必须为 4096 字节整数倍；
- tree depth、页号、页容量和 FID 校验；
- 叶页链访问预算，阻止循环页链；
- 页偏移 64 位中间计算；
- 实际条目数必须等于 trailer `total_value_count`；
- 任一结构错误都返回解析失败并清空条目。

合法零命中允许空候选；文件缺失或结构损坏禁止使用索引快速路径。

## 12. 验收判定

- **Blocked**：完整 FID 与 GDAL 不一致、损坏索引导致假空集、旧查询语义回归、候选扫描不安全或安装面泄露；
- **Fix then re-review**：独立代码审核发现 P0/P1；
- **Ready for formal validation**：代码审核无阻断项，但实际构建/测试/性能证据尚未齐全；
- **Accepted**：代码审核、GDAL ON/OFF、完整与并行 CTest、consumer、100K/10M 性能矩阵和回归门禁全部通过。
