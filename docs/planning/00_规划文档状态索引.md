## 5. 当前原则

- active 文档不得把计划项写成已通过证据；
- 合成测试和真实 ArcGIS/FileGDB 验收必须分开记录；
- 标准 WKT/WKB 语法不自动等于完整几何语义；
- `.spx` 候选不代替精确空间判断；
- GDAL fallback 必须记录后端、原因和 FID 映射；
- MultiPatch 在完整拓扑实现前保持 degraded；
- Draft PR 只用于 CI/审阅，未满足发布门禁前不自动合并。
