## 2. 当前性能状态

Phase A–H 的空间查询实现已合入 `main`。当前正式性能证据为全几何 1K–10M steady-state 和 10M Polygon fresh-open；Point、MultiPoint、Polyline 的 10M fresh-open 全矩阵、50M 阶梯和 35GB/5 亿级真实生产数据仍未完成独立验收，证据见 [空间查询公平基准验收记录](../evidence/spatial-query-baseline-2026-07-14.md)。

Phase H 计划现在作为主分支合入后的规模化验收和后续优化入口；只有新增矩阵触发门槛时，才继续实施按需 `.gdbtablx`、分布感知规划或并行扫描。Phase A–H 的过程与历史门槛已归档，不再作为当前实现状态来源。

## 4. 维护原则

- active 文档不得把计划项写成已通过证据；
- 合成测试、真实数据和历史推算必须分开记录；
- 当前支持范围内的发布结论以最终验收报告为准；
- `.spx` 只生成候选，不能代替精确空间判断；
- GDAL fallback 必须记录后端、原因和 FID 映射；
- MultiPatch 在完整拓扑实现前保持 degraded；
- 35GB/5 亿级真实性能和任何新增能力必须重新验收，不能从 10M 结果外推。
