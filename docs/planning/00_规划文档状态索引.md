## 2. v2 当前结论

- GeneralPolyline / GeneralPolygon 的 Curve flag/header 已修正。
- 曲线记录在 `nCurves > 0` 时明确 unsupported，空间过滤 fail closed。
- MultiPatch capability 已改为 degraded，明确不保留 part type 和完整表面拓扑。
- 本地构建通过。
- 功能 runner 最终结果：`401 passed / 11 skipped / 0 failed`。
- 两项 `RealDataReleaseContractTest` 在环境变量缺失时正确显示 SKIPPED，没有误报 PASS。
- 普通真实 FileGDB 和真实曲线 FileGDB 尚无可用样本，因此仍未完成真实数据验收。

## 4. 架构定位

当前推荐定位不是“完整替代 GDAL”，而是：

> fast-gdb 替代 FileGDB 高频只读矢量热路径；GDAL 保留多格式、重投影、复杂 SQL、完整几何语义和兼容性职责。

具体适用场景、风险和显式双路径架构见 [11_fast-gdb替换GDAL矢量能力分析.md](11_fast-gdb替换GDAL矢量能力分析.md)。
