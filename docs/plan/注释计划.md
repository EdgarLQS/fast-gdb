# 注释与文档维护计划

## 范围

注释工作只覆盖当前 Reader 产品：

- `src/edgar/explorgdb/common`；
- `src/edgar/explorgdb/reader`；
- `src/edgar/explorgdb/curve_gdal`；
- Reader 测试和工具；
- GDAL fixture/parity/boundary 测试。

自研 FileGDB Writer 已删除，不再为 Writer API、事务、恢复、发布或性能代码维护注释。

## 优先级

### P0

- Reader 对象所有权和生命周期；
- FID、tablx 和记录偏移；
- `.spx/.atx` 候选与最终复核；
- GeometryModel/WKB；
- QueryEngine/FeatureCursor 状态；
- 外部 GDAL 编辑前关闭 Reader、写后重开的边界。

### P1

- mmap/fd 平台差异；
- 安全回退条件；
- profiling 指标；
- Hybrid fallback；
- 损坏文件诊断。

## 禁止表述

- 不得写“fast-gdb Writer”；
- 不得暗示 Reader 与 GDAL 可安全同目录并发；
- 不得把 characterization 的 old/new 观测写成合同；
- 不得将 `.spx/.atx` 候选描述为最终结果；
- 不得将 `SKIPPED` 或无日志 CI 描述为通过。

## 注释格式

每个关键类型应说明：

- 所有权；
- 线程安全；
- 文件/映射生命周期；
- 错误语义；
- 外部写入失效条件；
- 性能代价和回退路径。
