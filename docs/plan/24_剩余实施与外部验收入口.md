## 二、最短路径：需要补的语料清单

如果只补语料，以下五项能解锁大部分剩余验收：

1. **带属性索引的大 GDB**：≥100 万行，数值、字符串、日期、GUID 各一个索引字段（ArcGIS 创建）。当前 `dltb_999999` 只有 `bsm` 一个 INT32 索引。
2. **补 `dlbz_index.atx`**：`dltb_999999` 已声明但文件缺失，补上即可测字符串大索引。
3. **带 `.spx` 的大表**：验证大表空间路径。
4. **附件 / 高级对象 / MultiPatch / 高位稀疏 v4**：可用仓库内生成器在 ArcGIS Pro 执行，或直接提供现成库。
5. **92/93 旧库**：恢复此前用过的 ArcGIS 9.x/10.x 样本，用于 v9 索引元数据调查。

语料放置建议：`test_data/gdb/<name>.gdb`（该目录被 `.gitignore` 忽略，不会误入库）。注意 `dltb_999999.gdb` 目前是双层同名目录，内层路径才是可打开的库。

## 四、验收口径

1. 每个勾选必须同时有实现、测试与可复现证据；缺一不勾。
2. 合成语料只证明合同，不替代 ArcGIS 真值；GDAL 结果也不单独作为正确性证明（其空间过滤已在真实语料上被证明不可靠）。
3. 性能结论标注平台、缓存状态与样本数，不外推。
4. 未协调外部 Writer 的检测只能写成 best-effort；同目录并发读写不属于支持能力。
