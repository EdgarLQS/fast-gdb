# SPX 源几何验证目录实施方案

状态：目录核心已实现，查询接入仍未完成，不是已有完整查询能力。延续总计划的完整只读目标，解决结构有效但缺项/错键导致的漏查；不能仅验证每个 FID 曾在一个 bbox 中出现。

当前进度：[核心组件与条件性证明测试](evidence/2026-11-08-spx-source-directory-core.md)覆盖源 FID 完整性、叶页真实包络及有界范围选择；尚未接入真实源解码、文件身份/transform、SPX 页读取、缓存失效和普通/融合查询。下列端到端验收继续未完成。

后续进度：[有界 SPX I/O 与身份适配层](evidence/2026-11-08-spx-source-index-io.md)已接通 SPX 页读取、路径/句柄身份、源稳定回调及事务式候选发布。规范源解码、实际 transform 绑定、全局缓存/失效和 QueryEngine 接入仍未完成。

后续进度：[实际表规范源回调](evidence/2026-11-08-spx-table-source.md)已固定 Geometry 字段与变换，接入实际表批量/全扫和规范模型包络，GDAL 六类图层与 NULL/Empty 对照通过；曲线安全包络和真实 MultiPatch 仍待验收。全局缓存/失效及普通/融合 QueryEngine 接入继续未完成。

## 完整性不变量

对所有活动、非空源几何，至少存在一个已验证叶页，其真实源几何包络包含该几何包络；查询时只可排除与查询窗口不相交的验证叶页。命中叶页中的 FID 最终仍由现有精确几何谓词复核。

目录范围来自源几何，不依赖 SPX 网格键或分隔键。因此一个要素即使跨多个网格，也只需至少一个叶页包含该 FID，即可通过该叶页的完整源包络保证任意窗口不漏候选。不能用物理网格键区间替代源包络。

## 实现顺序

1. 增加结构有效的缺项、错误键、重复/错误 FID、错误分隔键临时副本，以及 NULL/Empty、稀疏 FID、跨多个网格的线面；期望取自独立源几何全扫。先形成失败证据。
2. 沿叶链有界读取 FID，批量读取对应源行，逐叶累积真实完整包络。源行不可读时不发布目录；未知非空几何无法建立安全范围时明确失败/回退，不能当 NULL。
3. 用有界位图记录已经见到的活动 FID，再完整扫描源几何，证明所有非空几何均被覆盖。普通条目数等于 feature 数不构成证明；重复 FID 不能弥补遗漏。删除槽位、NULL/Empty 按明确合同处理。
4. 发布不可变叶页包络目录，按真实包络选择候选页，提取并去重 FID 后精确求值。普通及融合查询使用同一证明；原始物理 SPX API 保持独立语义。
5. 绑定 SPX/table/tablx/schema/geometry-transform 的同代身份，构建及查询前后校验。refresh/完整新快照强制失效；不保证活动外部 Writer 的并发 mmap 安全。
6. 设置目录、构建位图和候选预算；超预算、覆盖失败、未知布局等完整顺序回退，不发布部分证明，也不返回成功的部分结果。具体预算及规模阈值以实现和实测补齐，本文不先行承诺性能。

可以采用类似属性值目录的按页范围选择与有界 LRU，但需单独核算几何解码成本、长线面重复 FID 和大包络造成的选择性下降。没有必要为了复制所有 Writer 的栅格化细节而把未知网格规则当作真值。

## 验收顺序

先验证单点/多点及 source 变化，再验证长线、孔洞多面、曲线、非空 MultiPatch 的已支持结构；每类都检查多个内部窗口，而不是只查整体 extent。未知或不可求值结构按已有 Unsupported 合同处理。

正确性通过后重测 1K/10K/100K/1M/10M、冷热成本、低/高选择性、峰值内存及安装 consumer。真实多级 ArcGIS 索引仍是独立外部验收项，现有 125 个真实 SPX 仅含 level 0，不能替代该门禁。

未实现前，现有 SPX 查询仍存在有效但缺项/错键的完整性缺口；不得将本方案写成产品支持结论。
