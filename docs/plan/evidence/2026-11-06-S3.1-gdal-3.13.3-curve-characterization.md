# GDAL 3.13.3 curve fixture characterization

## Environment and input

- macOS arm64, conda-forge GDAL 3.13.3, OpenFileGDB, GEOS 3.14.1.
- Input: `test_data/gdb/参数化数据_liqs.gdb`.
- This records the output of GDAL 3.13.3 on the available fixture. It is not an
  ArcGIS control-point export or proof that each output preserves source curve
  semantics.

## Commands

```sh
/private/tmp/fast-gdb-gdal-3.13.3/bin/ogrinfo -ro -so test_data/gdb/参数化数据_liqs.gdb
/private/tmp/fast-gdb-gdal-3.13.3/bin/ogrinfo -ro -al -geom=SUMMARY test_data/gdb/参数化数据_liqs.gdb
```

OpenFileGDB successfully lists and reads 11 layers. The concise geometry
summary from `-al -geom=SUMMARY` is:

| Layer | Reported geometry | Feature geometry emitted by GDAL |
|---|---|---|
| 参数化_贝塞尔 | Multi Line String | MultiLineString / LineString |
| 参数化多线 | Multi Line String | MultiCurve / CompoundCurve with CircularString segments |
| 参数化椭圆 | Multi Line String | MultiLineString / LineString |
| 参数化椭圆弧 | Multi Line String | MultiLineString / LineString |
| 参数化圆 | Multi Line String | MultiCurve / CircularString segments |
| 参数化圆弧 | Multi Line String | MultiCurve / CircularString |
| 参数化圆弧和线 | Multi Line String | MultiCurve / CompoundCurve with line and CircularString segments |
| 参数化多面 | Multi Polygon | MultiSurface / CurvePolygon |
| 参数化椭圆_面 | Multi Polygon | MultiPolygon / Polygon |
| 参数化圆_面 | Multi Polygon | MultiSurface / CurvePolygon |
| 参数化圆弧_面 | Multi Polygon | MultiSurface / CurvePolygon |

The `参数化_贝塞尔`, `参数化椭圆` and `参数化椭圆弧` layers are exposed as
linear geometry in this GDAL run. CircularArc and compound CircularArc cases
remain OGR curve geometry, and several curved polygon cases remain
`CurvePolygon`. An API-wide statement that OpenFileGDB preserves every curve
kind would therefore be too broad for this fixture.

## Interpretation limits

- GDAL output does not expose the original Bezier/Ellipse control points in the
  reported geometry model above. Exact control-point semantics, error bounds,
  and per-feature ArcGIS parity remain open.
- No `Curve_Polyline_M_FC` layer is present. The `testcurve.gdb` directory still
  lacks `a00000004.gdbtable`, so its M-curve and other catalog-dependent cases
  remain unavailable.
- Existing fast-gdb integration evidence compares one discovered real curve
  feature for source-payload preservation and linearized type/bbox/length. It
  does not constitute a per-type Bezier/Ellipse/Z/M/CurvePolygon matrix.
- `S3.1` records the geometry policy and the tested cases; full real-curve
  equivalence remains open under the data checklist and `S0.2`.
