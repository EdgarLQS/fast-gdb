# S0.3 GDAL 3.13.3 local compatibility verification

## Environment

- Host: macOS 27, arm64.
- Compiler: AppleClang 21.0.0.21000099.
- Configuration: CMake Release build, `CMAKE_BUILD_TYPE=Release`.
- GDAL: conda-forge `gdal 3.13.3`, build `np2py315h417737f_5`; `libgdal-core 3.13.3`, build `h8348644_5`.
- Runtime identification: `/private/tmp/fast-gdb-gdal-3.13.3/bin/gdalinfo --version` reports GDAL 3.13.3, released 2026-08-13. The build cache selected `/private/tmp/fast-gdb-gdal-3.13.3/bin/gdal-config`; CMake found `/private/tmp/fast-gdb-gdal-3.13.3/lib/libgdal.dylib` version 3.13.3, and the test runner links `libgdal.39.dylib`.
- GEOS: 3.14.1.
- `ogrinfo --format OpenFileGDB`: the registered driver reports vector and raster, update, curve, Z and M support.
- Samples: `acceptance_metadata.gdb` and `参数化数据_liqs.gdb`; this does not repair the missing `testcurve.gdb/a00000004.gdbtable` or provide an M-curve layer.

## Build and test

Configure:

```bash
cmake -S . -B /private/tmp/fast-gdb-gdal-3.13.3-build \
  -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_PREFIX_PATH=/private/tmp/fast-gdb-gdal-3.13.3 \
  -DFAST_GDB_WITH_GDAL=ON \
  -DFAST_GDB_BUILD_UNIFIED=ON \
  -DFAST_GDB_BUILD_GDAL_DRIVER=ON \
  -DFAST_GDB_BUILD_ADAPTIVE_READER=OFF
```

Build and full CTest:

```bash
cmake --build /private/tmp/fast-gdb-gdal-3.13.3-build --parallel 4
FAST_GDB_REAL_DATASET=/Users/edgarlqs/Downloads/fast-gdb/test_data/gdb/acceptance_metadata.gdb \
FAST_GDB_CURVE_DATASET=/Users/edgarlqs/Downloads/fast-gdb/test_data/gdb/参数化数据_liqs.gdb \
ctest --test-dir /private/tmp/fast-gdb-gdal-3.13.3-build \
  --output-on-failure --parallel 4
```

Result: **487 discovered, 476 passed, 11 skipped, 0 failed**. Skips were the unconfigured AWS fixture, opt-in performance benchmarks, the BUILTIN-curve/REJECT-only contract case, and M-curve parity because the supplied curve sample has no `Curve_Polyline_M_FC` layer. No GDAL 3.13.3-specific failure was observed.

## Limits

- This is a macOS local build and test result. It does not prove the Ubuntu 3.13.3 CI job ran, nor Linux/Windows behavior.
- The existing GDAL 3.13.0 baseline remains a separate build; this evidence establishes compatibility at 3.13.3 for the currently available fixtures.
- It does not close the full multi-version create/update/index/REPACK matrix or replace the missing real M-curve, attachment, advanced-object and MultiPatch samples.

This updates the sample availability recorded above; it does not change the platform/version boundaries or prove per-type curve parity.
