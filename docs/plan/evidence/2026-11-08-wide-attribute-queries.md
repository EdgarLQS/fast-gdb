# S4.2 六操作符宽范围对照

本次补齐此前等值探针为主的规模测试，没有修改产品查询算法。总计划和 S4.2 保持未完成。

在既有真实 GDAL 数值 fixture 中增加六操作符 `= / != / < / <= / > / >=`，探针为 0.125。用 GDAL 全量读取的非 NULL 字段独立计算期望 FID；每种操作符分别对绑定索引入口和 WHERE 顺序入口执行三轮，逐次比较完整排序结果。

fixture 包含置换值和 NULL，不只是连续 FID 与数值一一对应的理想顺序。计时比较的是两个公开入口，包含结果物化，但 WHERE 还有表达式求值成本，因此不是纯 I/O 或单一算法基准。先运行索引再运行扫描，未清 OS 文件缓存，三轮中位数不能用作冷 I/O 或通用性能承诺。测试没有断言固定加速倍数。

## 已取得证据

macOS 10K 通过：[日志](2026-11-08-wide-attribute-queries/macos-10k.log)。Linux ARM64、GDAL 3.10.3 百万行六操作符和既有 63 个等值探针均通过：[日志](2026-11-08-wide-attribute-queries/linux-1m.log)。

| 条件 | 命中数 | 绑定索引 median ms | WHERE 顺序 median ms |
|---|---:|---:|---:|
| = | 1 | .039209 | 21.3321 |
| != | 989,689 | 58.7811 | 21.7597 |
| < | 494,844 | 26.4265 | 22.1303 |
| <= | 494,845 | 26.5233 | 22.2282 |
| > | 494,845 | 26.7375 | 22.3525 |
| >= | 494,846 | 26.5140 | 22.2930 |

千万行同样通过，见 [日志](2026-11-08-wide-attribute-queries/linux-10m.log)：等值只命中 1 行，索引/扫描 median .063501/217.459 ms；`!=` 命中 9,896,906 行，为 695.402/240.197 ms；四个半范围条件分别约 308–312/227 ms。每轮完整结果均与独立字段真值一致。

这证明非选择性条件仍有优化空间，不能将此前等值查询结果推广为所有操作符提速。产品源码未变，本次没有重跑全套或 sanitizer；对应产品基线仍为 `dd75ef6` 的既有记录，不声称新增测试已在其他配置运行。

## 后续动作

在验证目录已建立后，用叶页范围及候选数量估算选择性；非选择性条件选择完整字段扫描，避免生成、排序和复核大候选集。需保留同一原字段比较合同、源变化 guard、失败非部分结果及 NULL 语义，明确报告计划选择原因。先在六操作符、稀疏 FID、损坏索引与外部刷新合同验证，再重新测量收益；本次只建立数据依据，没有先行标记该优化完成。
