# S4.5 基线与当前版对照补充

## 环境与方法

- 主机：macOS 27 arm64，AppleClang 21，Release，GDAL 3.13.0。
- 基线：仓库提交 `67d4e31`；当前版：该基线加本工作区改动。
- 数据：同一个 GDAL OpenFileGDB 生成的 10M Point GDB，图层 `features`，字段 `feat_id`，路径 `/private/tmp/fast-gdb-s4-10m.gdb`。
- 测试：`ReaderRuntimeBenchmarkTest.ReadOnlyRuntimeProfileConfigured`，每轮 256 个随机 FID 读取和 10M 行全扫，各 5 个样本；Fast/GDAL 在每个样本内交替先后运行。Fast/GDAL FID、字段值和 ISO WKB digest 在所有运行中相等。
- 为让原基线接受同一只读基准，基线临时副本加入当前版的基准测试源码和 CMake 测试注册，并提供 `using RowSlot = uint32_t` 兼容旧接口；基线库源码未修改。基线临时目录为 `/private/tmp/fast-gdb-plan-22-baseline-67d4e31`。
- 每轮均未清理操作系统文件缓存。第二轮开始前两版和数据均已热身；第一轮有基线读盘计数，故第一轮不能作为严格冷/热配对。下面保留两轮数据，避免只呈现一个有利结果。

## 结果

时间单位为 ms；RSS 与磁盘读数是整个测试进程的峰值/累计值，不按 Fast 与 GDAL 分开归因。

| 运行 | 版本 | Fast 随机读 median / p95 | GDAL 随机读 median / p95 | Fast 全扫 median / p95 | GDAL 全扫 median / p95 | 进程峰值 RSS |
|---:|---|---:|---:|---:|---:|---:|
| 1 | 基线 `67d4e31` | 0.213 / 21.110 | 0.951 / 5.295 | 1,273.665 / 1,425.005 | 1,569.070 / 1,575.208 | 694,517,760 B |
| 1 | 当前版 | 0.102 / 0.349 | 0.532 / 1.023 | 1,458.986 / 1,460.205 | 1,563.049 / 1,576.245 | 883,834,880 B |
| 2 | 基线 `67d4e31` | 0.112 / 2.427 | 0.529 / 0.753 | 1,279.177 / 1,288.433 | 1,550.908 / 1,564.742 | 694,501,376 B |
| 2 | 当前版 | 0.139 / 0.224 | 0.540 / 1.081 | 1,453.872 / 1,455.993 | 1,581.007 / 1,606.884 | 883,998,720 B |

## 结论与边界

- 当前版 Fast 全扫相对基线在两轮中分别慢 14.5% 和 13.7%；它在这两轮中仍分别比 GDAL 快 6.7% 和 8.0%。这是值得后续剖析的扫描性能差异，当前 10M 基准没有全扫不慢于基线的门禁，不能据此判定功能验收失败。
- 随机读在第一轮比基线快约 52%，第二轮则慢约 24%；两轮方向不一致，不能据此宣称有稳定提升或退化。
- 当前进程峰值 RSS 约高 27%。这是进程级指标，无法区分 GDB 解码器、GDAL 或测试框架贡献；建议后续做分阶段/分后端内存剖析。
- 第一轮基线随机读和全扫分别报告 4,096,000 B 与 244,060,160 B 物理读盘，当前版分别为 32,768 B 与 0 B；第二轮所有计数均为 0。由于 OS 文件缓存未清且测量是进程级，不能把这些数字解释成逻辑读量或稳定的磁盘 I/O 差异。
- 10M 运行每轮仅 5 个样本，nearest-rank p95/p99 由极少数尾部样本决定。两轮是重复观测，不是大样本性能统计。

复现环境变量：

```sh
FAST_GDB_RUN_RUNTIME_BENCHMARKS=1 \
FAST_GDB_RUNTIME_BENCHMARK_PATH=/private/tmp/fast-gdb-s4-10m.gdb \
FAST_GDB_RUNTIME_BENCHMARK_LAYER=features \
FAST_GDB_RUNTIME_BENCHMARK_FIELD=feat_id \
FAST_GDB_RUNTIME_BENCHMARK_TRIALS=5 \
FAST_GDB_BENCHMARK_OUTPUT_DIR=<output-dir> \
<gdb_tutorial_test_runner> \
  --gtest_filter=ReaderRuntimeBenchmarkTest.ReadOnlyRuntimeProfileConfigured \
  --gtest_brief=1
```
