## Regeneration guard

`tests/createdata/powershell/generate_test_data.ps1` now checks that the
regenerated dataset contains `a00000004.gdbtable`, that every `.gdbtable` has a
matching `.gdbtablx` and vice versa, and that missing generated reference files
cause a non-zero exit status. This prevents a directory-only check from
reporting a partial GDB as successfully generated.

The script was not run on this macOS host: PowerShell and the required ArcGIS
Pro ArcPy runtime are unavailable here. Windows regeneration and its positive
validation result remain pending.
