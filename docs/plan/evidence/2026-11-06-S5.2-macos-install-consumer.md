# S5.2 macOS 安装包与外部 Consumer 验证

## 环境

- macOS 27.0 arm64；AppleClang 21.0.0；Release。
- GDAL 3.13.0。
- 安装前缀：`/private/tmp/fast-gdb-s4-install`。
- Consumer 构建目录均位于 `/private/tmp/fast-gdb-s4-consumer-{linear,hybrid,unified}`。

## 操作与结果

1. `cmake -S . -B build-s4-release -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON -DFAST_GDB_BUILD_FULL_TESTS=ON`
2. `cmake --build build-s4-release -j4` — 完整构建通过。
3. `cmake --install build-s4-release --prefix /private/tmp/fast-gdb-s4-install` — 安装 FastGDB Reader、Unified API、Hybrid API 和 GDAL 3.13 插件。
4. 对 `FAST_GDB_CONSUMER_TARGET=linear|hybrid|unified` 分别配置 `tests/package_consumer`，链接临时安装前缀，独立构建并运行 CTest。

本轮复核发现 `unified.h` 的相对 include 在源码树可解析，但安装包缺少
`reader/geometry/geometry_model.h` 这一嵌套路径。安装规则现额外保留该相对路径，
同时不移除原有扁平头文件以保持兼容。三种 Consumer 已重新构建；GDAL 自定义安装
位于临时目录，运行 unified CTest 时通过 `DYLD_LIBRARY_PATH` 显式提供
`/private/tmp/fast-gdb-gdal-3.13.3/lib`。

```sh
DYLD_LIBRARY_PATH=/private/tmp/fast-gdb-gdal-3.13.3/lib \
  ctest --test-dir /private/tmp/fast-gdb-s4-consumer-unified --output-on-failure
```

| Consumer | 构建 | CTest |
|---|---|---|
| linear | 通过 | 1/1 通过 |
| hybrid | 通过 | 1/1 通过 |
| unified | 通过 | 1/1 通过 |

本记录只证明 macOS / GDAL 3.13.0 安装包和三个公开目标可被外部项目消费。Linux 及 Windows 构建/安装、实际 ArcGIS 写后重读仍分别待其目标环境和数据验收。
