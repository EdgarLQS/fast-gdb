# S3.5：历史参考库几何输出对照

来源、固定下载 URL 和逐文件 SHA-256 沿用 [历史字段验收](2026-11-07-S3.5-gdal-historical-attributes.md)。环境 Debian 13.4 ARM64 / GCC 14.2 / GDAL 3.10.3 / Release。本轮仅改进测试，未修改解析器。

## 合同

将已有几何对照循环提取成共享测试函数，保留 testcurve 的 27 条曲线专项委托和 1 条自交面 fail-closed 断言；历史入口不采用这些专属样本预期，也不按层名跳过历史层。新增 `HistoricalGdbEveryNonCurveGeometryMatchesGdal`，由 `FAST_GDB_HISTORICAL_DATASET` 显式指定输入。

逐个 GDAL FID 确认原生行存在。非空间表要求双方均无几何字段/对象；空间行逐一比较 NULL/EMPTY 状态，非空几何由 GDAL 读取原生 WKB 后进行规范化，比较类型、Z/M 维度和全部坐标。任何非空几何读取失败或坐标差异均失败，并逐项输出诊断。没有为了让历史夹具通过而修改生产解析逻辑。

## 边界与后续

本次证明这些具体参考库的规范化几何输出与 GDAL 一致；不证明 ArcGIS 独立真值、原始曲线控制点、MultiPatch 部件保真、所有历史版本、索引查询或外部写后刷新。S3.3/S3.5 仍保留各自缺失语料和验收项。此前错误地将非空间表当作 NULL 空间几何进行比较的探索失败，已由本次明确分类的合同取代。
