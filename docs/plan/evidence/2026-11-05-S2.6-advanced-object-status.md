# S2.6 advanced ArcGIS object support status evidence

## Reported object properties

Each FastGdb `GDB_Items` summary now resolves the type UUID through
`GDB_ItemTypes`, reads `DatasetType` and geometry type from Definition XML, and
classifies Annotation, Dimension, Topology, Geometric Network, Network Dataset,
Network Diagram, Trace Network, Utility Network, Parcel Fabric, Terrain, TIN
and Mosaic Dataset objects. The summary separately reports whether the
definition is present, whether the name resolves to a physical table, and the
semantic status:

- `RawDefinitionOnly`: original catalog attributes/Definition can be read by
  UUID; specialized ArcGIS behavior is not implemented.
- `Unsupported`: an advanced object was identified but has no readable
  Definition; its business semantics remain unsupported.
- `NotApplicable`: the catalog object is not in the advanced-object taxonomy.

The Unified catalog inventory exposes the same fields. GDAL-only continues to
report the raw `GDB_Items` catalog capability as `Unsupported`, so it cannot
claim equivalent semantic classification.

## Sample and GDAL comparison

The local OpenFileGDB run reports 39 rows in `GDB_ItemTypes`, including Topology,
Geometric Network, Network Dataset, Trace Network, Utility Network, Parcel
Fabric, Terrain, TIN and Mosaic Dataset type names. `GDB_Items` has 19 objects in
the sample; the new inventory test confirms that none is an instance of those
advanced types. It also verifies that Roads resolves to type name `Feature
Class`, dataset type `esriDTFeatureClass`, geometry type
`esriGeometryPolyline`, and a physical table. Synthetic classifier tests cover
Annotation, Dimension, Topology, Network Dataset and Utility Network.

Commands:

```sh
/opt/homebrew/bin/ogrinfo -ro -oo LIST_ALL_TABLES=YES -al -geom=NO test_data/gdb/acceptance_metadata.gdb GDB_ItemTypes
/opt/homebrew/bin/ogrinfo -ro -oo LIST_ALL_TABLES=YES -so test_data/gdb/acceptance_metadata.gdb
```

This confirms catalog type names and the absence of advanced object instances
in the checked-in sample; it does not validate semantic interpretation against
an actual annotation, topology or network dataset. S2.6 remains unchecked until
ArcGIS-produced examples of those object classes are available.

## Limits

The classifier is intentionally conservative and uses `GDB_ItemTypes` names,
`DatasetType` and geometry type only. It reports no business semantics for
advanced objects and does not infer support from a readable physical table.
Unseen ArcGIS releases or localized/custom object types may remain unclassified
until their catalog definitions are added to conformance fixtures.

## 2026-11-06 follow-up: full registered taxonomy coverage

Added a no-GDAL contract suite covering Annotation, Dimension, Topology,
Geometric Network, Network Dataset, Network Diagram, Trace Network, Utility
Network, Parcel Fabric, Terrain, TIN and Mosaic Dataset, plus case-insensitive
matching and unknown object types. The suite passed in both GDAL ON and GDAL OFF
builds. It validates the classifier's current vocabulary, not the interpretation
of real advanced-object `Definition` content or object-specific business rules.

```sh
cmake --build build-s4-release --target gdb_tutorial_test_runner -j4
./build-s4-release/bin/gdb_tutorial_test_runner \
  --gtest_filter='MetadataContractTest.ClassifiesEveryKnownAdvancedObjectKind' \
  --gtest_brief=1

/private/tmp/fast-gdb-s2.2-no-gdal/bin/gdb_tutorial_test_runner \
```
