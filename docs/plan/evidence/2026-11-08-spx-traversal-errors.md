# SPX 遍历失败与空候选区分

继续空间候选完整性自查，本次解决已观察到的结构遍历失败传播，尚未证明 SPX 全部语义完整性。总计划保持未完成。

## 复现与实现

真实 GDAL 三点临时库中只破坏 SPX 根叶页条目计数，保持合法 trailer 和源表。旧 parse 成功后，查询访问到坏页直接返回，调用方把空候选当成功；普通 bbox 和 SpatialWhere 均漏行。见[修复前日志](2026-11-08-spx-traversal-errors/before.log)。

递归遍历现在返回成功/失败；页面读取失败、计数越界、无效选中子页以及遇到零 ObjectID 会沿调用栈传播失败。不同网格范围的任何一次遍历失败，都丢弃本次局部候选。`query_bbox` 新增可选 `query_succeeded` 输出，默认参数保留源码调用方式；调用者需要区分空结果与失败时应传入状态指针。

普通空间查询检查状态，失败时标记 SPX degraded 并完整扫描活动行；融合入口检查状态，失败时不消费候选，交给普通空间过滤回退。源行/谓词本身不能完整求值时仍按已有合同返回 Unsupported，而不是发布部分扫描结果。

保留合法空叶页及强制单子页根的兼容行为。空叶页与被人为清空的叶页不能仅凭本页结构区分，不宣称本次能发现所有缺失项。原始向量入口未传状态时仍只能得到空向量，不能据此判断是零匹配还是失败。

## 验证与限制

macOS 定向 30/30 通过：真实损坏 SPX 的普通/联合结果完整回退；既有空间索引与 v2 高位 ID 分支合同通过，新增可选状态的成功/非法请求断言。见[定向日志](2026-11-08-spx-traversal-errors/macos-focused.log)。

最终完整回归均配置用户曲线、固定元数据和历史参考库：macOS GDAL 3.13.0 共 611 项，593 PASS / 18 SKIP / 0 FAIL；Linux ARM64 GDAL 3.10.3 共 652 项，633 PASS / 19 SKIP / 0 FAIL，33.28 秒。见 [macOS](2026-11-08-spx-traversal-errors/macos-release.log)及 [Linux](2026-11-08-spx-traversal-errors/linux-release.log)。Linux 最终重新安装、重编译四类 Consumer 4/4 通过，见[安装日志](2026-11-08-spx-traversal-errors/linux-consumers.log)。没有将此前 macOS 安装结果当作本次新参数 ABI 证明。

不包含结构仍有效但漏项、重复/错误 FID、错误网格键、分隔键语义与源几何覆盖的完整证明。只有被访问的遍历错误会传播；未访问页面和任意排序损坏仍需独立验证。下一步必须建立源几何与网格项的覆盖合同，不能用“每个 FID 在某个 bbox 查询出现过”替代所有窗口的无漏查证明。

新增公开参数后下游应重编译，不承诺旧二进制 ABI。此次未重跑 sanitizer；既有 sanitizer 结论不作为本次通过证据。真实 ArcGIS、Windows、旧格式等原计划门禁继续保持未完成。
