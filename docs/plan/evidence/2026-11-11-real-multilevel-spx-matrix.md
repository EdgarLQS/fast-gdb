# 真实语料多级 SPX：源证明冷建/暖查矩阵与 oracle 修正

日期：2026-11-11。

状态：本机 macOS、GDAL 3.13.0 Release 实测完成。真实用户语料中存在 **depth 2/3 的多级 SPX**，源证明路线全部通过；同时发现旧基准用 GDAL 空间过滤当 oracle 在该语料上不可靠，已改为几何全量扫描真值。总计划仍未完成，本文不勾选任何外部语料/平台门禁。

## 一、语料与发现

样本为 `test_data/gdb/testcurve.gdb`（42 MB、279 文件、53 个 `.gdbtable`、44 图层）。其中两个性能层：

| 图层 | 物理表 | 要素数 | SPX |
|---|---|---|---|
| `Perf_Point_100k` | `a00000033` | 100,000 | `depth=2`，296 页，295 叶页 |
| `Perf_Point_1M` | `a00000036` | 1,000,000 | `depth=3`，2952 页，2942 叶页 |

[2026-11-08 语料清单](2026-11-08-spx-corpus-levels/macos-inventory.json) 当时已记录 `depths {1: 41, 2: 3, 3: 1}`，即 45 个真实 SPX 中有 4 个是多级树。此前计划文字把清单里的 `levels {"0": ...}`（条目的**叶层级**统计，全部条目本来就落在 level 0）误读成"只有单层"，据此得出"真实语料全为 level 0、无法做多级验收"。该结论不成立，本记录予以修正。

本次源证明在 1M 层实际读取 2,957 页 = 2,942 叶页 + 15 内部页；100k 层 300 页 = 295 叶页 + 5 内部页。内部页遍历确实发生，不是只读叶链。

## 二、oracle 不可用：GDAL 空间过滤与几何真值不一致

旧基准用 `OGRLayer::SetSpatialFilterRect` 的结果作为 FID oracle。实测该过滤在这份语料上返回：

| 窗口 | GDAL 过滤 | 几何全扫真值 | Fast 匹配 |
|---|---:|---:|---:|
| 1M，25% 窗口（25000..75000） | 0 | 2,536 | 2,536 |
| 1M，80% 窗口（5278.6..94721.4） | 0 | 7,964 | 7,964 |
| 1M，full（-1000..101000） | 111 | 10,209 | 10,209 |
| 100k，full | 33 | 1,013 | 1,013 |

GDAL 的过滤走物理网格键；这份语料的索引键与源几何不完全一致（源证明正是为此设计成不依赖物理键），所以用它作 oracle 会把正确结果判成错误。另注意到过滤结果与调用顺序有关：先查询负坐标窗口后再查正坐标窗口，GDAL 会得到与真值一致的结果，说明它自身在索引与扫描之间的切换也不稳定。**GDAL 空间过滤不能作为该语料的正确性真值。**

## 三、基准修改

`test_spatial_source_proof_benchmark.cpp`：

- 新增 `run_gdal_geometry_truth`：GDAL 全量遍历源要素，按几何包络与窗口相交计算 FID 真值；FID 仍按 `fid-1` 映射到逻辑行槽。
- Fast 的 `matched_fids` 只与几何真值比较；GDAL 过滤仅保留为计时参考。
- 过滤结果与真值不一致时打印 `[gdal-filter] <case> differs from geometry truth: filter=... truth=...`，不再静默当成基准失败。

该修改只影响门禁环境变量启用的基准，不改变产品代码和默认测试。

## 五、验证

- 两个图层 × 5 窗口的 Fast `matched_fids` 与几何全扫真值完全相等，`SpatialSourceProofBenchmark.ColdBuildMatrix`、`WarmQueryMatrix` 均 PASSED。
- 1M 层峰值 RSS 89.3 MB，100k 层 56.1 MB（整进程，含 mmap/缓存页）。
- 与 2026-11-09 合成 uniform 10M 矩阵相比，这份真实语料的冷建更慢（1M 约 161 ms 对合成 10M 约 2.0 s 是不同规模，不可直接比较）；暖查仍在毫秒级。

## 六、边界

1. `testcurve.gdb` 是用户提供的真实样本，创建来源与逐层 ArcGIS 真值仍未独立确认；本文只说"真实语料多级树可解析并完成源证明"，不说"已通过 ArcGIS 原生多级索引验收"。
2. 只覆盖 5 个固定窗口、2 个图层；任意窗口与更多网格配置仍未证明。
3. GDAL 过滤的差异是 GDAL 3.13.0 在本语料上的行为记录，不代表 ArcGIS 行为，也不作为 Fast 正确性的唯一依据——正确性依据是几何全扫真值。
4. 未做物理冷 I/O（清 OS 缓存）、Windows、安装 consumer 的复测。
