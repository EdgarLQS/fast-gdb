## Build and full test suite

Configured and built the complete project, including the shared runtime, GDAL driver module, command-line tools, test runners, and verification tools. The Linux build exposed and fixed three portability issues: an explicit `<cmath>` include for `std::isnan`, position-independent code for static libraries linked into shared targets, and tests incorrectly treating `OGRLayer::SetSpatialFilterRect` as a status-returning method.

Ran the full Release CTest suite with both the checked-in `acceptance_metadata.gdb` and the supplied `testcurve.gdb` configured:

- 590 tests discovered; 573 passed, 17 skipped, 0 failed; 29.38 seconds.
- All supplied-data row/attribute, non-curve geometry, spatial-window, curve, sparse-FID, million-point, and CRS regression contracts passed.
- Skips are opt-in attachment/AWS/performance benchmarks, an unsupported OpenFileGDB index-delete operation, and an explicitly unsupported curve backend. These skips do not count as passed coverage for the corresponding optional feature.

Two Adaptive Reader update contracts initially exposed overlayfs timestamp coalescing. A small same-size rewrite can change bytes without changing the reported `mtime`/`ctime` inside the current timestamp quantum; the metadata-keyed tablx cache then cannot distinguish that rewrite. The tests now wait 20 ms before these synthetic GDAL writes, directly confirm the updated row through OpenFileGDB, and compare the resulting GDAL one-based FID to FastGDB's zero-based row slot. The create-feature and index/extent-refresh contracts each passed 30 consecutive runs, followed by the full 590-test run above. This evidence therefore covers updates whose source identity metadata advances; it does not prove detection of a rewrite that leaves all cache-key metadata identical on the direct new-reader path (these tests do not call `Dataset::refresh()`). If unconditional detection of that case is part of the Reader contract, deterministic source-generation invalidation or content validation on open remains an open item.
