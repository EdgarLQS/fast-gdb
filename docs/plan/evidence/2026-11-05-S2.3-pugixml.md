# S2.3 pugixml XML parser evidence

## Pinned dependency

- Upstream release: [pugixml v1.16](https://github.com/zeux/pugixml/releases/tag/v1.16)
- Source archive: `https://github.com/zeux/pugixml/releases/download/v1.16/pugixml-1.16.tar.gz`
- SHA-256: `4cee1ca4aad395170f4c7a07824f3bdd41f28316c6e1e1090a1425b278ec0b4b4`
- License: MIT, vendored with the upstream source under `third_party/pugixml/src/LICENSE.md`

The parser implementation is compiled into `explorgdb_reader_lib`; the public
reader headers do not expose pugixml types, and this dependency does not depend
on GDAL.

## Implemented behavior

- Replaced XML text/tag scanning in metadata decoding and the unified layer
  default path with pugixml DOM traversal.
- Match prefixed or default-namespace element names by QName local name and
  decode standard XML entities in values and attributes.
- Retain the exact source XML string in domain, layer, relationship and
  feature-dataset raw payloads.
- Classify Feature Dataset definition XML through the same DOM inspection
  path and carry its state into Reader and Unified workspace snapshots.
- Distinguish a SQL NULL Definition from an empty Definition string. Metadata
  inspection reports `Missing`, `Empty`, `Malformed`, `UnknownStructure`, or
  `Available`, with a diagnostic for non-available cases.
- Recognize the ArcGIS `GPCodedValueDomain2`, `GPRangeDomain2`, and
  `GPBooleanDomain2` roots observed in the acceptance GDB.

## GDAL ON verification

Build:

```sh
cmake --build build-open-source-hybrid --target fast_gdb_runtime gdb_tutorial_test_runner fast_gdb_unified_test_runner --parallel 4
```

Metadata reader and real ArcGIS workspace metadata tests:

```sh
./build-open-source-hybrid/bin/gdb_tutorial_test_runner --gtest_filter='MetadataReaderTest.*:ReaderContractTest.ReadsWorkspaceMetadataWithoutOpeningALayer'
```

Result: 16/16 passed. Coverage includes prefixed namespace names, entity
decoding, exact raw XML retention, NULL-versus-empty Definition, malformed and
unknown XML classification, actual ArcGIS domain roots, and workspace
relationship definitions.

Unified metadata tests:

```sh
./build-open-source-hybrid/bin/fast_gdb_unified_test_runner --gtest_filter='UnifiedFastFacadeTest.ExposesWorkspaceAndLayerMetadataSnapshots:UnifiedGdalFacadeTest.GdalOnlyPreservesFeatureDatasetGroups'
```

Result: 2/2 passed.

## GDAL OFF verification

```sh
cmake --build /tmp/fast-gdb-s2.2-no-gdal --target fast_gdb_unified_test_runner gdb_tutorial_test_runner --parallel 4
```

The GDAL OFF build passed. The source-reader workspace metadata test and the
unified native metadata snapshot test both passed (2/2). The build emitted
pre-existing `#include_next` portability warnings from the POSIX compatibility
headers; pugixml produced no build errors.

## Scope boundary

This verifies the implemented XML structures and current acceptance data. It
does not establish semantic coverage of every ArcGIS XML version, rich
Documentation/ItemInfo metadata, or unknown GDB object types; those remain in
S2.6 and cross-version acceptance. S2.4 separately adds catalog object
inventory and raw Definition/attribute access.
