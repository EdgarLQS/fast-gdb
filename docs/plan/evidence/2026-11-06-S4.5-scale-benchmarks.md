# S4.5 只读运行基准与规模数据验证

## 范围与环境

- 主机：macOS 27.0，arm64；Release，`-O3 -DNDEBUG`。
- 对照：系统 GDAL 3.13.0 / OpenFileGDB。
- 数据：GDAL OpenFileGDB 生成的确定性网格点数据；每个规模都验证 Fast 与 GDAL 的 FID 集合一致。
- 100K 性能门禁：101 轮；每轮做 256 个随机 FID 读取、100K 全表扫描、10% 空间覆盖的联合查询、80% 空间覆盖且走 ATX 的联合查询。门禁定义为 Fast 的新句柄打开、随机读取、全扫和两档联合查询中位数均不慢于 GDAL。
- 百万级空间矩阵：1K、10K、1M 各 5 轮、5 档覆盖率；10M 于 2026-11-06 对 1%、10%、30%、80%、全覆盖各跑 5 轮。

100K 计时按 nearest-rank 计算；101 个样本下 p99 为排序后的第 100 个样本。空间矩阵使用已有的稳态基准，表中显示中位数和 p95。生成数据在 `/private/tmp/fast-gdb-s4-{1k,10k,1m,10m}.gdb`，测试完成后由系统临时目录管理。

## 100K 运行结果

时间单位为 ms；吞吐量单位随操作而异：打开为 Dataset/s，随机读取为 feature/s，全扫为 feature/s，联合查询为结果 feature/s。

| 操作 | Fast median / p95 / p99 | GDAL median / p95 / p99 | Fast 吞吐 | GDAL 吞吐 |
|---|---:|---:|---:|---:|
| 新句柄打开 | 0.232 / 0.246 / 0.258 | 0.306 / 0.331 / 0.355 | 4,319 /s | 3,268 /s |
| 已打开 Reader 的 `open()` / GDAL 图层查找 | 0.076 / 0.079 / 0.083 | 0.000042 / 0.000084 / 0.000125 | 13,238 /s | 23,809,524 /s |
| 256 个随机 FID 读取 | 0.081 / 0.085 / 0.104 | 0.349 / 0.366 / 0.382 | 3,171,928 /s | 734,400 /s |
| 100K 全表扫描 | 13.601 / 13.911 / 14.006 | 15.969 / 16.223 / 16.371 | 7,352,378 /s | 6,262,231 /s |
| 10% 空间覆盖 SpatialWhere，1,000 个结果 | 0.324 / 0.340 / 0.349 | 0.664 / 0.700 / 0.723 | 3,085,229 /s | 1,506,119 /s |
| 80% 空间覆盖 SpatialWhere，8,000 个结果 | 2.124 / 2.157 / 2.178 | 3.208 / 3.269 / 3.302 | 3,765,666 /s | 2,493,506 /s |

100K 中位数门禁通过。低覆盖融合查询绕过 ATX；高覆盖查询使用 ATX，共 198 页、访问 22 页、扫描 10,240 个索引项。Fast 与 GDAL 的全扫、随机读取及两组联合查询摘要/FID 断言均相等。

### 10M 随机读取与全量扫描

为补齐大规模读取数据，`ReadOnlyRuntimeProfileConfigured` 增加了可配置的只读运行入口，可指定现成 GDB、图层、整数字段和样本轮数，不重写输入数据。对同一个 10M Point 夹具，稳态下各跑 5 轮；每轮随机读取同一组 256 个 FID、再完整扫描 10M 行。Fast/GDAL 摘要均包含 FID、`feat_id` 和 ISO WKB，所有随机与全扫 digest 相等。

| 操作 | Fast median / p95 / p99 ms | GDAL median / p95 / p99 ms | Fast 吞吐 | GDAL 吞吐 |
|---|---:|---:|---:|---:|
| 256 个随机 FID，5 轮 | 0.102 / 18.793 / 18.793 | 0.571 / 5.310 / 5.310 | 2,508,771 feature/s | 448,205 feature/s |
| 10M 全量扫描，5 轮 | 1,435.716 / 1,617.432 / 1,617.432 | 1,566.941 / 1,570.482 / 1,570.482 | 6,965,164 feature/s | 6,381,860 feature/s |

五轮样本的 nearest-rank p95/p99 等于最大值，应按小样本观察值解读。该测试检查结果 digest 是否一致，没有对 10M p95 加性能门禁：随机读取 Fast 中位数较快，但 p95 高于 GDAL；全扫 Fast 中位数较快，p95 与 GDAL 接近。进程级物理读取累计值分别为随机读 Fast 4,161,536 bytes、GDAL 1,064,960 bytes，全扫 Fast 243,961,856 bytes、GDAL 49,152 bytes；本轮进程峰值 RSS 约 809 MB。这些值均不是分 backend 独立隔离测量，且 OS 文件缓存未清。

复现命令、stdout、结构化 JSON 与原 100K benchmark 兼容性回归分别记录在 [10M coverage log](2026-11-06-S4.5-10m-rerun.log)、[10M random/scan log](2026-11-06-S4.5-10m-random-scan.log)、[10M JSON](2026-11-06-S4.5-10m-runtime.json)、[100K 回归 log](2026-11-06-S4.5-100k-regression.log) 和 [100K JSON](2026-11-06-S4.5-100k-runtime-rerun.json)。

与优化前基线 `67d4e31` 的 10M 随机读取和全扫对照另有两轮复测，包含两版 Fast/GDAL 的 median/p95、摘要一致性及计量边界，见 [基线对照补充](2026-11-06-S4.5-before-after-comparison.md)。当前版全扫较基线慢约 14%，但仍快于 GDAL；随机读取两轮方向不一致。该全扫差异作为后续性能分析线索，不以小样本推断稳定退化。

## 读盘与内存指标边界

- 100K 进程峰值 RSS 为 58,802,176 bytes；这是整次测试进程的高水位，包含 GDAL 生成基准 GDB 的阶段，不代表 Fast 或 GDAL 单独的峰值。
- 使用 macOS `proc_pid_rusage` 记录各操作前后的进程物理磁盘读取字节。打开、随机读取、全扫和 Fast 查询的累计计数为 0；GDAL 的 10% 联合查询累计读到 835,584 bytes。该计数不包含命中操作系统文件缓存的数据，也不是逐文件逻辑读取量。
- 新句柄打开是在同一进程内反复创建/关闭 Reader 或 Dataset，不能称为操作系统文件缓存冷启动；本机没有清除文件缓存。证据明确记录为 fresh-context open。热调用则是在已打开句柄上测量。
- 10M/1M 空间矩阵只记录稳态查询时间和候选漏斗指标；RSS、读盘计数以及 p99 的详细对照来自 100K 运行基准。

## 复现入口

- 编译：`cmake --build build-s4-release --target gdb_tutorial_test_runner generate_large_gdb -j4`
- 100K 完整运行：`FAST_GDB_RUN_RUNTIME_BENCHMARKS=1 build-s4-release/bin/gdb_tutorial_test_runner --gtest_filter=ReaderRuntimeBenchmarkTest.ReadOnlyRuntimeProfile100K`
- 空间矩阵：`FAST_GDB_RUN_SPATIAL_BENCHMARKS=1 FAST_GDB_BENCHMARK_PATH=<gdb-path> FAST_GDB_BENCHMARK_LABEL=<label> FAST_GDB_BENCHMARK_TRIALS=<n> build-s4-release/bin/gdb_tutorial_test_runner --gtest_filter=SpatialDensityBenchmark.DensityMatrixConfigured`
- 2026-11-06 10M 五档复跑：`FAST_GDB_RUN_SPATIAL_BENCHMARKS=1 FAST_GDB_BENCHMARK_PATH=/private/tmp/fast-gdb-s4-10m.gdb FAST_GDB_BENCHMARK_LABEL=10M_grid_point FAST_GDB_BENCHMARK_TRIALS=5 build-s4-release/bin/gdb_tutorial_test_runner --gtest_filter=SpatialDensityBenchmark.DensityMatrixConfigured --gtest_brief=1`；完整输出见同目录 log。
- 10M 随机读取/全扫：设置 `FAST_GDB_RUN_RUNTIME_BENCHMARKS=1`、`FAST_GDB_RUNTIME_BENCHMARK_PATH=/private/tmp/fast-gdb-s4-10m.gdb`、`FAST_GDB_RUNTIME_BENCHMARK_LAYER=features`、`FAST_GDB_RUNTIME_BENCHMARK_FIELD=feat_id`、`FAST_GDB_RUNTIME_BENCHMARK_TRIALS=5` 和 `FAST_GDB_BENCHMARK_OUTPUT_DIR=/private/tmp/fast-gdb-s4.5-runtime`，再运行 `build-s4-release/bin/gdb_tutorial_test_runner --gtest_filter=ReaderRuntimeBenchmarkTest.ReadOnlyRuntimeProfileConfigured --gtest_brief=1`。
- 100K helper 回归：`FAST_GDB_RUN_RUNTIME_BENCHMARKS=1 FAST_GDB_BENCHMARK_OUTPUT_DIR=/private/tmp/fast-gdb-s4.5-runtime ./build-s4-release/bin/gdb_tutorial_test_runner --gtest_filter=ReaderRuntimeBenchmarkTest.ReadOnlyRuntimeProfile100K --gtest_brief=1`（1/1 通过）。
- 生成器支持 `--count`、`--geometry point`、`--distribution grid`、`--output`。
