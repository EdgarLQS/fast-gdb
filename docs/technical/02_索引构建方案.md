# FileGDB 索引读取与外部构建方案

## 1. 定位

fast-gdb 只读取和验证 FileGDB 索引，不创建或修改索引文件。

- `.spx`：空间候选；
- `.atx`：属性候选；
- `.gdbindexes`：属性索引元数据。

索引创建、删除和重建统一由 GDAL/OpenFileGDB 或 ArcGIS 完成。

## 2. Reader 原则

```text
index lookup
    → candidate FIDs
    → load real records/geometries
    → complete WHERE / spatial recheck
    → final matches
```

索引永远不是最终正确性来源。

## 3. 安全解析

Reader 必须验证：

- 文件长度和页边界；
- page id、capacity 和 entry count；
- leaf chain 是否循环；
- FID 是否为合法活动记录；
- metadata 与物理文件是否匹配；
- 字符串和数值编码是否明确。

任何验证失败都应关闭索引路径并回退，而不是返回部分候选。

## 4. GDAL 构建索引

调用方需要创建或重建索引时：

```text
close all fast-gdb Readers
→ open GDAL/OpenFileGDB update Dataset
→ create/delete/rebuild index
→ close SQL result sets and Dataset
→ reopen fast-gdb Reader
```

禁止在 fast-gdb 持有 `.spx/.atx` 页面或 table/tablx mmap 时修改索引。

## 5. 写后验证

重开 Reader 后至少验证：

- 顺序扫描结果；
- 无索引 WHERE/空间结果；
- 索引候选路径结果；
- candidate superset；
- final match parity；
- GDAL 查询对照。

## 6. 不支持

- fast-gdb 创建 `.spx/.atx`；
- fast-gdb 更新 `.gdbindexes`；
- Reader 活动期间 GDAL 重建索引；
- 写后复用旧索引对象；
- 依赖索引结果跳过最终复核；
- 将索引文件存在等同于索引正确。

## 7. 测试矩阵

| 场景 | 预期 |
|---|---|
| 无索引 | 全表安全回退 |
| GDAL 新建属性索引后重开 | `.atx` 与完整 WHERE 一致 |
| GDAL 删除属性索引后重开 | 自动回退 |
| GDAL 重建空间索引后重开 | 候选覆盖真实命中 |
| 损坏 `.atx/.spx` | fail closed / fallback |
| 高低选择性 | 规划路径合理且结果一致 |
| 外部 REPACK 后重开 | 重新加载 tablx 和所有索引状态 |
