## 1. 建议审核顺序

### 第一组：公共契约与分派

1. `src/edgar/explorgdb/reader/query_engine.h`
2. `src/edgar/explorgdb/reader/query_engine.cpp`
3. `src/edgar/explorgdb/reader/query_engine_combined.cpp`

确认：

- `SpatialWhere` 只追加到 `QueryKind` 末尾；
- 复用已有 bbox 和 `where_clause`；
- 非法 bbox/WHERE 返回 `spatial-where:invalid`；
- 其他 QueryKind 的分派和语义未改变；
- `CombinedQueryMetrics` 只用于诊断，不影响结果。

### 第二组：WHERE 语义

1. `query_where_internal.h`
2. `query_where_internal.cpp`
3. `tests/edgar/explorgdb/reader/test_query_where_internal.cpp`

确认：

- 比较、AND、OR、IN 和括号与原 WHERE 子集一致；
- NULL 比较遵循 GDAL OpenFileGDB 语义：`!=` 可命中，`=`、范围比较和 `IN` 不命中；
- 字段绑定大小写不敏感；
- 非法数字、未知字段和错误语法 fail closed；
- `FeatureRecord` 与 `FieldRef` 求值结果一致；
- 内部头未进入安装包。

### 第三组：索引规划与候选完备性

1. `gdb_indexes.h/.cpp`
2. `gdb_catalog.h/.cpp`
3. `gdb_attribute_index.h/.cpp`
4. `query_engine_combined.cpp`

确认：

- 字段通过 `.gdbindexes` 映射索引名，不猜测索引名等于字段名；
- 裸字段与 `LOWER(field)`/未知函数表达式正确区分；
- `.atx` 只产生候选，最终完整 WHERE 复核；
- `.atx` 候选在交集前排序、去重；
- 非 BMP、`!=`、无法证明物理类型的编码主动回退；
- 合法零命中与解析失败可区分；
- 页链循环、页越界、计数不一致、FID 0 和截断文件全部 fail closed。

### 第四组：候选字段扫描

1. `gdb_table.h`
2. `gdb_table_field_scan.cpp`

确认：

- 候选 FID 越界、删除行和无效偏移不会被读取；
- nullable bitmap 与字段布局使用既有单一事实源；
- mmap 返回的 `FieldRef` 生命周期只在回调期间有效；
- fd 路径不会把复用缓冲区引用保存到回调外；
- 扫描失败时按 FID 使用 canonical `read_record_by_fid()`；
- 最终结果恢复数值 FID 升序。

### 第五组：测试与安装面

1. `tests/edgar/explorgdb/reader/test_gdb_attribute_index_safety.cpp`
2. `tests/usegdal/test_spatial_where_*.cpp`
3. `tests/package_consumer/main.cpp`
4. `cmake/FastGdbInstall.cmake`

确认：

- GDAL OFF 能编译纯 C++ WHERE 和索引安全测试；
- GDAL ON 现场生成 FileGDB 并逐 FID 对照 GDAL；
- Point、Polyline、Polygon 含洞、MultiPoint、Z/M/ZM、NULL 和 Unicode 均覆盖；
- `.spx`/`.atx` 缺失和损坏均覆盖；
- 每个 CTest 使用独立临时目录，可安全 `ctest -j`；
- package consumer 只包含公开头；
- `query_where_internal.h` 未安装。

## 2. P0 审核检查点

任何一项成立都应阻断合并：

- 损坏 `.atx` 被解释为合法空候选；
- `.atx` 候选不完备却直接作为最终结果；
- 未执行精确空间判断；
- 字符串截断、Unicode、NULL、NaN 或函数索引导致漏 FID；
- 页链循环、页号溢出或无界遍历；
- 候选扫描读取错误行、越界或悬空 `FieldRef`；
- `SpatialWhere` 改变既有 `WhereClause`、`SpatialBbox` 或属性查询结果；
- 完整 FID 与 GDAL 不一致。

## 3. P1 审核检查点

- 公共头依赖传递包含；
- GDAL OFF 构建引用 GDAL 头或符号；
- 测试共享固定临时 GDB，导致并行竞争；
- benchmark 写入硬编码执行路径或 correctness；
- fallback_reason 与 execution_path 不一致；
- package consumer 无法使用安装后的 `SpatialWhere`；
- 指标统计与真实候选/复核数量不一致；
- CMake glob、安装规则或测试发现未包含新增文件。

  -DCMAKE_BUILD_TYPE=Release \
