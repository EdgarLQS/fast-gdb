# 功能与基准测试覆盖矩阵

本文把“能力、测试证据、数据、平台和 CI 门禁”放在同一张表中。测试数据的生成和路径规则见[测试数据准备与跨平台验证指南](03_测试数据准备与跨平台验证.md)；本矩阵只记录覆盖状态和缺口。

## 状态定义

| 状态 | 含义 |
|---|---|
| `GATED` | CI 中执行，正确性失败会阻断合并 |
| `OBSERVE` | 可重复执行并记录结果，暂不按耗时阻断 |
| `MANUAL` | 依赖外部数据、ArcGIS Pro、大磁盘或冷缓存环境 |
| `MISSING` | 尚未形成可复现的自动化证据 |
| `BOUNDARY` | 产品明确不支持或只提供降级行为，不属于测试遗漏 |

## 基准测试矩阵

| 场景 | 入口 | 数据规模 | 对照 | 状态 | 判定 |
|---|---|---:|---|---|---|
| 写入：GDAL single/batch 与 binary writer | `W0_ReleaseEvidence_1K`、`W1_*`–`W3_*`、`WriterTest.T_W03_BulkWritePerformance` | 1K/10K/100K/1M/10M | GDAL 或同平台 main | `OBSERVE` | JSON/CSV 记录 median、p95、RSS、磁盘和正确性；先校验重开数量 |
| 宽字段写入 | `W7_WideAttributes_*` | 10K × 10/50/100 Float64 + Point | GDAL | `OBSERVE` | macOS 回读正确性通过；Writer 中位耗时约为 GDAL 6.2–7.6 倍，作为待优化基线 |
| 几何复杂度写入 | `W8_Geometry_*` | 10K × Point/10 点线/面/3 part 线/带洞面 | GDAL | `OBSERVE` | macOS 首尾属性、类型族、顶点数、包络回读通过；Writer 中位耗时约为 GDAL 3.3–10.2 倍 |
| Z/M 维度写入 | `W9_Dimension_*` | 10K × Point XY/XYZ/XYM/XYZM | GDAL | `OBSERVE` | macOS 维度标志和首尾 X/Y/Z/M 回读通过；Writer 中位耗时约为 GDAL 10.1–11.8 倍 |
| Writer 长稳 | `W10_WriterLongSteady_100KCycles` | 100K 循环，默认 1800 秒 | 同一 manifest 的逐轮结果 | `MANUAL` | macOS 1800.2 秒/3281 轮通过，预热后 RSS +0.5 MiB；其他平台待统一执行 |
| 顺序读取与零拷贝扫描 | `R1_*`、`R2_*` | 100K/10M | GDAL、per-record | `OBSERVE` | 记录 median/p95 和总要素数 |
| Reader 长稳 | `R7_ReaderLongSteady_100KCycles` | 100K 重开 + 空间/FID/全表扫描，默认 1800 秒 | 固定 warmup 结果 | `MANUAL` | macOS 1800.0 秒/51,904 轮通过，扫描 51.904 亿行，预热后 RSS +0.016 MiB |
| 空间密度矩阵 | `SpatialDensityBenchmark.*` | 1M/10M | current-vs-main、GDAL | `GATED` | current-vs-main 最大回退 5% |
| 属性查询 | `R5_*`、`R6_*` | 100K | GDAL | `OBSERVE` | FID 集合先一致，再比较耗时 |
| 索引创建 | `benchmark_index_creation <gdb_path>`、`IndexCreatorTest.*` | 100K | GDAL/历史值 | `OBSERVE` | 输出耗时、文件和查询正确性 |
| 完整工作流 | `C1_*`–`C6_*` | 100K | GDAL、binary writer | `OBSERVE` | 写入、索引、读取、查询全链路通过 |
| Windows mmap/异步/冷缓存 | `run_spatial_acceptance.ps1` | 1M/10M | main A/B | `MANUAL` | 只有提供 RAMMap 才能声明 strict-cold |
| 35GB/5亿级真实数据 | 尚无统一入口 | 生产级 | macOS 资源未就绪 | `MISSING` | 当前暂缓；不从 10M 或长稳结果外推 |

普通功能回归不得默认执行耗时基准；读写、索引和完整工作流由 `FAST_GDB_RUN_FULL_BENCHMARKS=1` 显式开启，空间查询仍由 `FAST_GDB_RUN_SPATIAL_BENCHMARKS=1` 控制。空间 current-vs-main 脚本输出 CSV；Writer、索引和完整工作流输出 schema v2 JSON 与汇总 CSV，字段包含代码版本、平台、编译器、GDAL 版本、数据 manifest、场景、缓存状态、采样次数、median、p95、吞吐量、分段/总耗时、峰值及增长 RSS、磁盘、数量、循环数和正确性。当前只以 macOS 为 Writer 执行与验收平台。场景编号、manifest 和结果 schema 保持平台无关；Windows/Linux 接入暂缓，不进入当前 CI 改造、排期或完成率。

## CI 分层

| 层级 | 运行内容 | 频率 |
|---|---|---|
| 核心门禁 | 现有纯 C++ 几何与 GDAL 回归保持不变 | push/PR |
| 空间门禁 | Linux/macOS current-vs-main 10M；Windows mmap/I/O | 相关 PR/手工 |
| 真实数据验收 | ArcGIS 曲线、外部业务 GDB、完整矩阵 | 发布前/手工 |
| macOS Writer 契约 | 场景编号、manifest、JSON/CSV schema、跳过原因和安装消费 | 计划 18 M18.1 |
| 性能专项 | 宽表、复杂几何、内存、并发、长稳、生产级规模 | 后续专项 |
