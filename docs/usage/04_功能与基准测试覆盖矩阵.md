# 功能与基准测试覆盖矩阵

当前分支：`codex/spatial-attribute-query`。联合查询、完整 Feature 流式迭代和
`move_to(fid)` 的实现与静态自检已完成；实际构建、CTest、consumer 和性能证据仍缺，
状态为 **Code review ready / Formal acceptance blocked**。

## 状态定义

| 状态 | 含义 |
|---|---|
| `GATED` | 已在正式门禁中执行，失败会阻断合并 |
| `CODE_READY` | 实现和测试代码完成，可审核，但尚无完整运行证据 |
| `OBSERVE` | 可重复执行并记录，暂不按耗时阻断 |
| `MANUAL` | 依赖外部数据、ArcGIS Pro、大磁盘或冷缓存 |
| `MISSING` | 尚未形成可复现证据 |
| `BOUNDARY` | 明确范围外或降级能力 |
