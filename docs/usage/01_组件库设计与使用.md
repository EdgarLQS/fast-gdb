# fast-gdb Reader 组件设计与使用

## 1. 产品组件

fast-gdb 只提供 Reader 产品：

```text
fast_gdb::linear
    纯 C++ FileGDB Reader

fast_gdb::hybrid
    fast-gdb Reader 主路径
    + GDAL 复杂几何回退
```

`src/edgar/usegdal` 是未安装的 GDAL 参考/测试组件，不构成 FileGDB Writer 产品。项目不提供 `GdbBatchWriter`、`GdbTransaction` 或其他写入包装 API。

## 2. 读取对象层次

```text
GdbCatalog
    └── CatalogResolver
            └── ResolvedTable
                    └── GdbTableParser
                            ├── FeatureRecord
                            ├── GeometryValue
                            └── QueryEngine / FeatureCursor
```

### 生命周期规则

- `FeatureCursor` 的生命周期不得超过对应 `QueryEngine`；
- `QueryEngine` 使用的表、catalog 和解析结果必须保持有效；
- mmap、fd/HANDLE 和索引页面缓存由对应 Reader 对象拥有；
- 对目标 GDB 进行外部写入前，必须销毁整条 Reader 对象链。

## 3. 基本读取

```cpp
#include "gdb_catalog.h"
#include "catalog_resolver.h"
#include "gdb_table.h"

GdbCatalog catalog;
if (!catalog.scan("data.gdb")) return false;

CatalogResolver resolver(catalog);
if (!resolver.load()) return false;

const auto resolved = resolver.resolve("cities");
if (!resolved) return false;

GdbTableParser table(resolved->table_path);
if (!table.open()) return false;
if (!table.load_tablx(resolved->tablx_path)) return false;

FeatureRecord record;
if (table.read_record_by_fid(0, record)) {
    // consume fields
}
```

## 4. 完整要素和 WKB-first

```cpp
FeatureRecord record;
GeometryValue geometry;
if (table.read_feature_by_fid(0, record, geometry)) {
    if (geometry.valid()) {
        consume_wkb(geometry.wkb);
    }
}
```

WKT 是按需调试输出：

```cpp
const auto wkt = geometry.to_wkt();
```

## 5. 查询

```cpp
QueryEngine engine(catalog, *resolved);
if (!engine.open()) return false;

QueryRequest request;
request.kind = QueryKind::SpatialWhere;
request.xmin = 0;
request.ymin = 0;
request.xmax = 100;
request.ymax = 100;
request.where_clause = "population >= 1000";

FeatureCursor cursor = engine.open_cursor(request);
QueryFeature feature;
while (cursor.next(feature)) {
    consume(feature);
}
```

`.spx` 和 `.atx` 仅用于生成候选；最终结果必须执行完整属性和几何复核。

## 6. 多线程读取

推荐每个线程独立创建 Reader 对象：

- 不共享 `GdbTableParser`；
- 不共享活动 `FeatureCursor`；
- 不共享可变 `QueryEngine`；
- 只共享不可变配置和业务层路由信息。

## 7. 外部 GDAL 编辑

fast-gdb 不提供写入 API。调用 GDAL update 前：

1. 停止新查询；
2. 等待所有 cursor 结束；
3. 销毁 QueryEngine、table 和 catalog；
4. 关闭 mmap 和文件句柄；
5. 使用 GDAL/OpenFileGDB 独占编辑；
6. `GDALClose()`；
7. 从零重建 Reader。

同一个 `.gdb` 目录的 GDAL 写入和 fast-gdb 并发读取不支持。详见 [GDAL 写入与 fast-gdb 读取边界](11_GDAL写入与fast-gdb读取边界.md)。

## 8. CMake 使用

### Linear

```cmake
find_package(fast_gdb 0.1 CONFIG REQUIRED)
target_link_libraries(my_reader PRIVATE fast_gdb::linear)
```

### Hybrid

```cmake
find_package(fast_gdb 0.1 CONFIG REQUIRED)
target_link_libraries(my_reader PRIVATE fast_gdb::hybrid)
```

不存在 `fast_gdb::writer`。
